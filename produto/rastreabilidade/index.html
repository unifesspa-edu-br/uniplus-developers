Rastreabilidade

Esta página publica a matriz de rastreabilidade do Uni+: permite navegar da necessidade institucional até a evidência de verificação, sem renumerar requisitos nem transformar lacunas em entregas concluídas.

Estado da publicação

Esta é a primeira matriz pública curada. Ela consolida a hierarquia, o status, a política de backlog e a verificação esperada de cada requisito. Vínculos de issue, PR e código que ainda não existem aparecem como lacuna honesta, não como entrega.

Fonte canônica​

A matriz segue a taxonomia de rastreabilidade e a cadeia mínima:

origem -> requisito -> decisão -> issue -> PR -> código -> teste -> documentação

O uniplus-developers publica a visão consolidada. Contratos, código, testes e ADRs técnicas continuam pertencendo aos repositórios donos; quando referenciados, os links apontam para a branch main do repositório dono.

Política para lacunas​

  • Campo vazio significa ausência real de vínculo publicado, não esquecimento.
  • Dependências externas aparecem com status dependencia_externa.
  • Incrementos futuros aparecem como incremento_planejado.
  • Itens históricos permanecem rastreáveis e apontam substituição quando houver.
  • Links técnicos apontam para a branch main do repositório dono.
