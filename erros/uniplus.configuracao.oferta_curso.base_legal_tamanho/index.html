A base legal da oferta de curso excede o tamanho máximo

Código
uniplus.configuracao.oferta_curso.base_legal_tamanho
Título emitido
A base legal da oferta de curso excede o tamanho máximo
Status HTTP
422
Campo type
https://unifesspa-edu-br.github.io/uniplus-developers/erros/uniplus.configuracao.oferta_curso.base_legal_tamanho
Situação
Publicado
Módulo
Configuração
Onde aparece
  • Criação de uma oferta de curso
  • Atualização de uma oferta de curso
Rastreio
uniplus-api#749

O que aconteceu​

A base legal da oferta excede o tamanho máximo aceito: 500 caracteres.

Este é o mesmo campo cuja ausência, para programa diferente de REGULAR, é recusada pelo erro de base legal obrigatória — aqui a causa é o tamanho excedido, não a ausência.

Como resolver​

Reduza a base legal para até 500 caracteres.
