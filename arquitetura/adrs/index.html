Índice de ADRs

As decisões arquiteturais do Uni+ são registradas como ADRs (Architecture Decision Records) no formato MADR 4.0. Esta página é o índice público delas — um ponto de partida para navegar as decisões por repositório.

Esta página indexa, não duplica

Conforme a ADR-0002 do portal, o portal indexa ADRs sem duplicar autoridade. A verdade de cada decisão é o arquivo docs/adrs/ no repositório dono. Os links abaixo apontam para o índice canônico de cada repositório no GitHub, sempre atualizado.

Índices canônicos por repositório​

RepositórioEscopo das decisõesÍndice canônico
uniplus-apiBackend .NET — arquitetura, persistência, mensageria, contrato REST, segurançadocs/adrs/
uniplus-webFrontend Angular — consumo de API, codegen, padrões de UI, autenticaçãodocs/adrs/
uniplus-developersPortal público — arquitetura do portal e governança editorialdocs/adrs/

Decisões de natureza institucional ou histórica sensível permanecem em repositório privado e não são publicadas aqui; quando relevantes, aparecem apenas como resumo público sem dados reais.

Um recorte curado das decisões com maior impacto para quem implementa, opera ou integra com o Uni+. Os links apontam para o arquivo canônico no GitHub.
