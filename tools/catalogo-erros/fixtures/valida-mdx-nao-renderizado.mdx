## O que aconteceu

Esta fixture não menciona o alias na prosa. As três ocorrências acima
são sintaxe MDX que nunca aparece ao leitor: um atributo JSX
(`rotuloInterno`), um comentário `{/* */}`, e — logo abaixo, fora deste
parágrafo — uma instrução `import`. Prova que a checagem de alias só
olha para o texto renderizado, não para o código-fonte MDX inteiro.

## Como resolver

Não se aplica — fixture de teste; o validador deve aceitá-la.

import NuncaUsado from 'RN15-modulo-inexistente';
