# Índice de ADRs

As decisões arquiteturais do Uni+ são registradas como **ADRs** (*Architecture
Decision Records*) no formato [MADR 4.0](https://adr.github.io/madr/). Esta
página é o **índice público** delas — um ponto de partida para navegar as
decisões por repositório.

:::warning[Esta página indexa, não duplica]
Conforme a
[ADR-0002 do portal](https://github.com/unifesspa-edu-br/uniplus-developers/blob/main/docs/adrs/0002-governanca-editorial-fontes-canonicas-portal-publico.md),
o portal **indexa** ADRs sem duplicar autoridade. A verdade de cada decisão é o
arquivo `docs/adrs/` no **repositório dono**. Os links abaixo apontam para o
índice canônico de cada repositório no GitHub, sempre atualizado.
:::

## Índices canônicos por repositório

| Repositório | Escopo das decisões | Índice canônico |
|---|---|---|
| `uniplus-api` | Backend .NET — arquitetura, persistência, mensageria, contrato REST, segurança | [docs/adrs/](https://github.com/unifesspa-edu-br/uniplus-api/blob/main/docs/adrs/README.md) |
| `uniplus-web` | Frontend Angular — consumo de API, codegen, padrões de UI, autenticação | [docs/adrs/](https://github.com/unifesspa-edu-br/uniplus-web/blob/main/docs/adrs/README.md) |
| `uniplus-developers` | Portal público — arquitetura do portal e governança editorial | [docs/adrs/](https://github.com/unifesspa-edu-br/uniplus-developers/blob/main/docs/adrs/README.md) |

> Decisões de natureza institucional ou histórica sensível permanecem em
> repositório privado e **não** são publicadas aqui; quando relevantes, aparecem
> apenas como resumo público sem dados reais.
