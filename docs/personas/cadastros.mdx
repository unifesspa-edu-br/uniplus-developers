# Personas fictícias

Catálogo de **30 pessoas fictícias** com perfil completo para uso em **testes de
formulários, telas e integração**. Todos os dados são **gerados e fictícios** —
nenhuma pessoa real.

:::warning Regra
Use **apenas** estas personas nos exemplos e testes. Não invente CPF, nome ou
e-mail avulso — reutilize um cadastro desta lista para manter os exemplos
consistentes e garantir que nenhum dado real entre na documentação.
:::

:::note Sobre os dados
A tabela mostra os campos principais; clique em **Detalhes** para abrir o perfil
completo, com um botão para **copiar** cada campo (útil para colar em testes).
CPF, RG, CEP e telefones estão mascarados; os e-mails usam domínios genéricos
fictícios. Senhas foram omitidas de propósito — defina a senha no próprio
fixture do teste quando precisar de um cenário de login.

Uma parte das personas tem **nome social** (RN02 — prioridade absoluta em
listas e documentos), com nome de sexo oposto ou neutro, para exercitar esse
fluxo nos testes.
:::
