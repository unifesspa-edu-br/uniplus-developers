# Requisitos

Esta página é o ponto público de consulta dos requisitos do Uni+. A tabela abaixo
publica o primeiro recorte curado do MVP do módulo Seleção, com identificadores
estáveis, status honestos e os campos da taxonomia pública.

:::info[Estado da publicação]
Esta é a primeira fonte pública curada. Os registros nascem de dado estruturado
versionado no `uniplus-developers`
([`src/data/produto/requisitos-mvp-selecao.ts`](https://github.com/unifesspa-edu-br/uniplus-developers/blob/main/src/data/produto/requisitos-mvp-selecao.ts)),
não da matriz interna de trabalho. Apenas campos públicos seguros são exibidos,
sem dados reais.
:::

páginas narrativas complementam o entendimento, mas não substituem o registro

## Critérios para publicar

- O requisito possui `requisito_id`, grupo, tipo, nível, status e recorte.
- O texto está livre de dados pessoais, anexos reais e histórico sensível.
- Itens agregadores não são tratados como entrega implementável isolada.
- Links para ADRs, código, contratos e testes apontam para a branch `main` do
  repositório dono.
- Lacunas de implementação aparecem como status explícito, não como omissão.
