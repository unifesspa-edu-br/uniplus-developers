## O que aconteceu

A **ação quando indeferido** informada não é um dos dois tokens do domínio
fechado: `RECLASSIFICAR_AC` ou `RECLASSIFICAR_REGRA_EDITAL`.

Esta ação é opcional (a modalidade pode não declarar nenhuma). Este erro só
dispara quando um token é informado e não é um dos dois válidos.

## Como resolver

Informe um dos dois tokens válidos — `RECLASSIFICAR_AC` ou
`RECLASSIFICAR_REGRA_EDITAL` — ou omita o campo se a modalidade não declara
ação para o candidato indeferido.
