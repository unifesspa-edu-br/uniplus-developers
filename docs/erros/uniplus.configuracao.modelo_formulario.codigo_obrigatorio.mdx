## O que aconteceu

A criação de um modelo de formulário (`POST /api/configuracao/admin/modelos-formulario`) veio com o campo `codigo` presente, mas vazio ou só com espaços. O código é o que identifica o modelo no cadastro e o distingue dos outros modelos do mesmo uso; ele é imutável depois da criação.

Este código não cobre o `codigo` ausente do JSON nem enviado como `null`. O corpo da criação declara o código como texto não anulável, e o ASP.NET Core recusa o campo ausente ou nulo na validação do modelo, com 400, antes de o pedido chegar às regras do Uni+. Essa recusa não tem código do catálogo de erros. Só o código presente e em branco responde 422 com o código desta página.

A recusa vem na lista `errors` da resposta, com `field` igual a `codigo`. Quando o conteúdo do modelo também tem recusas, as do conteúdo vêm antes na lista, e a resposta leva todas. Nada é gravado.

## Como resolver

Informe um código de até 60 caracteres e repita o pedido.
