## O que aconteceu

O **tamanho máximo em MB** informado é zero ou negativo.

Este campo é opcional (o tipo pode não declarar um teto), mas quando
informado precisa ser estritamente positivo — assim como formatos aceitos,
é um default classificatório, sem efeito material em runtime.

## Como resolver

Informe um valor positivo, ou omita o campo se o tipo não tem teto de
tamanho a declarar.
