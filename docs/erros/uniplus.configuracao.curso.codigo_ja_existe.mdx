## O que aconteceu

O **código** informado já pertence a outro curso vivo. O código é a
chave natural do curso, único entre cursos vivos (comparação
sensível a maiúsculas/minúsculas) — mas **editável**, diferente de
cadastros com código imutável: um curso removido não reserva o código
para sempre.

## Como resolver

Escolha outro código, ou confira se o curso que já usa este código é
o registro que você pretendia atualizar.
