processo segue a regra anterior, de um formulário por finalidade.

:::

## O que aconteceu

O processo tem quantos formulários forem necessários (UNI-REQ-0144), e cada um é
identificado por um código que não se repete dentro do processo. O código
informado já pertence a outro formulário dele, de modo que a gravação (ou a
aplicação de um modelo) substituiria o formulário errado. A recusa sai com
**409**, e o `detail` diz o código repetido.

## Como resolver

Escolha outro código para o formulário novo, como `HABILITACAO_COMPLEMENTAR` no
lugar de `HABILITACAO`. Se a intenção era mudar o formulário que já existe,
grave-o pelo código dele, em vez de criar um novo. Depois disso, grave de novo.
