## O que aconteceu

Duas ou mais entradas de `modalidadeIds`, na mesma distribuição de vagas,
resolveram para o mesmo código de modalidade. Cada modalidade participa de
uma oferta no máximo uma vez.

Esta checagem só roda **depois** que os Ids informados são resolvidos contra
o catálogo de modalidades (por isso não acumula com
[`vo_base_invalido`](./uniplus.selecao.configuracao_distribuicao_vagas.vo_base_invalido.mdx),
[`pr_fora_do_limite`](./uniplus.selecao.configuracao_distribuicao_vagas.pr_fora_do_limite.mdx)
e
[`modalidades_vazias`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidades_vazias.mdx)
— essas três só liberam a passagem para esta consulta quando vêm limpas para
**todas** as distribuições do payload, então nunca aparecem na mesma resposta
que esta). A partir daqui, o processamento é por distribuição: a primeira
distribuição do payload cuja resolução falhar interrompe a passada — as
distribuições seguintes do mesmo payload não chegam a ser conferidas.

Dentro de uma distribuição, porém, esta checagem **acumula** com outras
violações de coerência do conjunto de modalidades já resolvido (por exemplo,
uma referência cruzada de composição/remanejamento apontando para um código
fora da oferta) — todas no mesmo array `errors[]`, sob o campo
`distribuicaoVagas[<índice>].modalidadeIds`.

Este código também aparece no **descarte de retificação**: reconstruir o
grafo a partir do envelope congelado recomputa cada
`ConfiguracaoDistribuicaoVagas` a partir dos mesmos insumos — a mesma
checagem do domínio roda de novo sobre as modalidades congeladas. Mas, nesse
caminho, ela sai **sozinha**: o descarte propaga só a primeira violação
encontrada, sem o array `errors[]` que a definição usa para acumular várias
de uma vez — mesmo que a configuração congelada tenha mais de um problema.

## Como resolver

Revise a lista `modalidadeIds` da distribuição indicada e garanta que cada
modalidade apareça no máximo uma vez.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
