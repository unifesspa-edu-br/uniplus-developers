## O que aconteceu

Só o item com ajuste recomendado pela proteção de dados tem uma classificação recomendada. Este item está pendente, aguardando decisão, já aprovado ou reprovado.

## Como resolver

Confira a situação do item. O aceite só cabe depois de um ajuste recomendado.
