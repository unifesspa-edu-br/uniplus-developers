## O que aconteceu

A operação foi recusada porque o **CEP** do endereço informado não foi
preenchido.

O endereço estruturado ao Geo via CEP é opcional como um todo — o
cadastro pode não declarar endereço algum. Mas quando o objeto de
endereço é enviado, o CEP é obrigatório dentro dele: é a âncora de
presença do endereço — como o CEP sempre resolve ao menos a uma cidade,
é a partir dele que o resto do endereço (logradouro, bairro, cidade) é
composto no cliente a partir do serviço Geo.

Esta validação é compartilhada pelo mesmo value object
(`ReferenciaEnderecoGeo`, no Kernel) que valida o endereço de três
cadastros distintos, em dois módulos: a sede da Instituição (Organização
Institucional), o Campus e o Local de Oferta (Configuração). O código
desta página é o que a API hoje emite para os três — a resolução do
`type` segue a chave interna do validador compartilhado, comum aos três
cadastros, e não distingue de qual módulo a chamada partiu.

## Como resolver

Informe o CEP dentro do objeto de endereço, ou omita o objeto de endereço
por completo se a entidade (instituição, campus ou local de oferta) não
tiver endereço estruturado a declarar.
