## O que aconteceu

O valor informado para **vagas anuais autorizadas** é negativo.

Este campo é o teto de vagas anuais autorizadas no e-MEC — **não** são as
vagas de um certame específico, que pertencem ao edital, no módulo Seleção.
O valor é opcional (a oferta pode não declarar um teto), mas quando
informado precisa ser zero ou positivo.

## Como resolver

Informe um valor zero ou positivo, ou omita o campo se a oferta não tem teto
de vagas e-MEC a declarar.
