## O que aconteceu

O código informado respeita o formato (`^[A-Z_]+$`), mas não é o de nenhum
tipo de banca do catálogo da seleção, que é fechado: o cadastro aceita só os
códigos dos tipos que o catálogo traz.

Este cadastro entrega o **tipo** da banca. A composição da banca (membros,
atas, deliberações) não é modelada aqui.

## Como resolver

Use o código de um tipo de banca do catálogo, que `GET /api/configuracao/vocabularios/tipos-banca` lista.
