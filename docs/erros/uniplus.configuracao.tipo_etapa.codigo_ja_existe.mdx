## O que aconteceu

O código informado já foi reservado por outro tipo de etapa.

Diferente de cadastros com soft-delete (modalidade, fase canônica), o tipo
de etapa nunca é removido, só desativado — e a checagem de unicidade
considera **todos** os registros, ativos ou não. Um código já usado por um
tipo desativado continua indisponível para reuso.

## Como resolver

Use um código diferente.
