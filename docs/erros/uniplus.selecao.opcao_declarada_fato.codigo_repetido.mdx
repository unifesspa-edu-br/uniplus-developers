## O que aconteceu

A lista de opções enviada para o fato traz duas ou mais opções com o mesmo
código. O código é o que identifica a opção nas condições do processo, como a
exigência de um documento para quem escolheu determinada opção. Com códigos
repetidos, não haveria como saber a qual das opções a condição se refere, e a
API recusa. Nada foi gravado.

Os códigos são comparados exatamente como foram escritos, depois de retirados
os espaços do início e do fim, e letras maiúsculas e minúsculas contam como
diferentes.

## Como resolver

Deixe cada opção com um código diferente das demais, ou remova a opção que
sobrou em duplicidade, e envie a lista completa de novo.
