## O que aconteceu

O identificador do documento não corresponde a nenhum documento deste processo seletivo. A
API dá a mesma resposta para o documento que não existe e para o documento de outro
processo: a rota de um processo não confirma a existência de documento alheio.

## Como resolver

Liste os documentos do processo e use o identificador de um deles. Se o documento ainda não
foi enviado, inicie o envio: a resposta traz o identificador que as demais operações usam.
