## O que aconteceu

A **descrição** da modalidade excede o tamanho máximo aceito: 300
caracteres.

A descrição é um dos dois campos editáveis mesmo numa modalidade do catálogo
legal fixo (o outro é a base legal) — esta validação de tamanho vale para
todas as modalidades, fixas ou não.

## Como resolver

Reduza a descrição para até 300 caracteres.
