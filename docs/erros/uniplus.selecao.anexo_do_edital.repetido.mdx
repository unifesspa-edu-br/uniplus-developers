## O que aconteceu

O mesmo documento consta mais de uma vez no edital: em dois anexos, ou como anexo e como
documento principal. Cada arquivo publicado do edital tem um lugar só, e o edital atesta o
hash de cada documento.

## Como resolver

Mantenha cada documento uma única vez. Para publicar o mesmo arquivo sob dois nomes, não é
preciso: um anexo basta. Se são arquivos diferentes, envie cada um e use o identificador
próprio.
