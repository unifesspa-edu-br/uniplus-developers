## O que aconteceu

O processo declara que a inscrição é feita pelo sistema, e o formulário de
inscrição não coleta todos os dados do conjunto básico do candidato (UNI-REQ-0151:
nome, CPF, RG, nacionalidade, data de nascimento, endereço e os demais dados
básicos) na seção reservada a eles. A API confere os dados do conjunto nessa
seção do formulário de inscrição, e falta pelo menos um. A recusa sai com
**422**, e o `detail` diz quantos dados faltam.

## Como resolver

Restaure a seção reservada dos dados básicos do formulário de inscrição: grave de
novo o formulário e, depois, os itens dele, o que repõe a seção com todos os dados
do conjunto. Ou parta do modelo de inscrição do tipo do processo, que já traz o
conjunto básico completo. Depois disso, publique de novo.
