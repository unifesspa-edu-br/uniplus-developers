## O que aconteceu

A **natureza legal** informada não é um dos quatro tokens do domínio
fechado: `COTA_RESERVADA`, `AMPLA`, `SUPLEMENTAR` ou `OUTRA_MODALIDADE`.

A natureza legal tem valor padrão: se omitida, a modalidade assume `AMPLA`
silenciosamente. Este erro só dispara quando um token é informado e não é um
dos quatro válidos.

## Como resolver

Informe um dos quatro tokens válidos — `COTA_RESERVADA`, `AMPLA`,
`SUPLEMENTAR` ou `OUTRA_MODALIDADE` — ou omita o campo para aceitar o padrão
`AMPLA`.
