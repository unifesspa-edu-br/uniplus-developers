O campo `type` de uma resposta de erro da API aponta para a página do código.
Cada página mostra o status HTTP, explica a recusa e indica como resolver.

O catálogo acompanha o commit sincronizado da branch `main` da API. A versão
implantada pode estar em outro commit.
