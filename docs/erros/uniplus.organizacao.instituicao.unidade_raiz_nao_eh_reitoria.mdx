## O que aconteceu

A unidade declarada como raiz da instituição existe, mas não é do
**tipo reitoria**.

O vínculo da instituição com sua unidade raiz representa a reitoria — o
topo da hierarquia organizacional. Apontar para uma unidade de outro
tipo (pró-reitoria, centro, faculdade etc.) quebraria essa semântica:
não haveria mais garantia de que "a unidade raiz da instituição" e "a
reitoria" são a mesma coisa.

## Como resolver

Informe o Id de uma unidade cujo tipo seja reitoria. Se a unidade que
você pretendia usar não é do tipo reitoria, verifique se ela deveria ser
reclassificada, ou se a unidade reitoria correta é outra no cadastro.
