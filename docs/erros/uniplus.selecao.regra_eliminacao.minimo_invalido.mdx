## O que aconteceu

Uma regra de eliminação com o código `ELIM-CORTE-REDACAO` informou
`minimo` negativo. Esta regra elimina o candidato que não atingir a nota
mínima na redação — um corte negativo não tem interpretação válida.

O processamento é sequencial por regra: a primeira com valor inválido
interrompe a passada, sem acumular com nenhuma outra violação.

Este código também aparece no **descarte de retificação**: reconstruir o
grafo a partir do envelope congelado recria cada regra de eliminação a
partir dos mesmos campos — a mesma checagem roda de novo.

## Como resolver

Informe um `minimo` maior ou igual a zero para a regra
`ELIM-CORTE-REDACAO`.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
