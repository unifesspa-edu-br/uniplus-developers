## O que aconteceu

O pedido de aplicar um modelo de formulário
(`POST .../formularios/aplicacoes-de-modelo`) chegou a um processo que não está
em rascunho. Aplicar um modelo substitui por inteiro o formulário da finalidade
do modelo, e a API só admite essa operação com o processo em rascunho, ainda não
publicado. Nada foi alterado.

A API atual não emite mais este código: o processo publicado recusa o pedido com
o código de [mutação bloqueada depois da publicação](./uniplus.selecao.processo_seletivo.mutacao_pos_publicacao_bloqueada.mdx),
e o processo encerrado ou cancelado, com o de
[mutação fora de estado editável](./uniplus.selecao.processo_seletivo.mutacao_fora_de_estado_editavel.mdx).

## Como resolver

Aplique o modelo antes de publicar o processo. Depois da publicação, nenhuma
operação de escrita do formulário é aceita (o conjunto de itens, os termos e o
cabeçalho com as etapas): o processo publicado só muda pela retificação em ato
único.
