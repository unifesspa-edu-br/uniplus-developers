## O que aconteceu

Já existe uma fase canônica **viva** com o código informado.

A unicidade é sobre fases vivas — um código de uma fase removida (soft
delete) pode ser reutilizado. A checagem cobre tanto o caminho comum
(consulta prévia) quanto a corrida entre duas criações concorrentes com o
mesmo código: o índice único parcial do banco garante a exclusividade, e uma
violação nele é traduzida para este mesmo erro.

## Como resolver

Use um código diferente, ou — se a intenção é a fase que já existe —
atualize a fase viva existente em vez de criar uma nova.
