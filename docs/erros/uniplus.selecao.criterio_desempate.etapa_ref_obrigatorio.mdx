## O que aconteceu

Um critério de desempate com a regra `DESEMPATE-MAIOR-NOTA-ETAPA` não
informou `etapaRef`. Este critério desempata comparando a nota que os
candidatos empatados tiraram numa etapa específica — sem dizer qual etapa,
não há o que comparar.

Esta checagem roda na montagem dos argumentos do critério, depois que a
regra já foi resolvida contra o catálogo — ver
[`regra_nao_encontrada`](./uniplus.selecao.criterio_desempate.regra_nao_encontrada.mdx).
Não acumula com nenhuma outra violação — é a primeira que falhar que
interrompe o processamento.

Este código verifica só que o campo foi informado — não confere se a
`etapaRef` de fato corresponde a uma etapa existente no processo (essa é
uma checagem separada, feita pela raiz do agregado ao definir os
critérios, contra as etapas do processo).

## Como resolver

Informe `etapaRef` com o `Id` de uma etapa do processo para todo critério
com a regra `DESEMPATE-MAIOR-NOTA-ETAPA`.
