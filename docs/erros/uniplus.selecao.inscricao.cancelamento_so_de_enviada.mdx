## O que aconteceu

O pedido tenta cancelar uma inscrição que ainda é rascunho. O cancelamento vale
só para a inscrição já enviada (UNI-REQ-0033); o rascunho não tem número nem
comprovante e sai por outro caminho.

## Como resolver

Para desistir do rascunho, descarte-o (UNI-REQ-0023). Depois do descarte, é
possível iniciar uma inscrição nova. Se preferir continuar, termine o rascunho
e envie a inscrição.
