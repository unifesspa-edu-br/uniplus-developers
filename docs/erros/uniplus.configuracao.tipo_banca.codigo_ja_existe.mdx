## O que aconteceu

Já existe um tipo de banca **vivo** com o código informado.

A unicidade é sobre bancas vivas — um código de uma banca removida (soft
delete) pode ser reutilizado. Como o conjunto canônico tem só quatro
códigos possíveis, este erro tende a aparecer ao tentar recriar um tipo que
já está cadastrado e ativo.

## Como resolver

Se a intenção é a banca que já existe, atualize-a em vez de criar uma nova.
