## O que aconteceu

A lista de revisões foi pedida com o parâmetro `situacao` num valor que o sistema não conhece. Os valores aceitos são `em_andamento` e `concluida`. O filtro é aplicado no servidor, antes da paginação, e por isso o valor inválido é recusado em vez de devolver uma página vazia. Nenhuma revisão foi listada.

## Como resolver

Envie `situacao=em_andamento` ou `situacao=concluida`, ou omita o parâmetro para listar todas as revisões.
