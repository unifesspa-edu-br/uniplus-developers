## O que aconteceu

A operação foi recusada porque o **código** do tipo de banca não foi
preenchido.

O código (ex.: `BANCA_ENTREVISTA`) é a chave natural do cadastro — único
entre bancas vivas e imutável após a criação.

## Como resolver

Informe um código para o tipo de banca.
