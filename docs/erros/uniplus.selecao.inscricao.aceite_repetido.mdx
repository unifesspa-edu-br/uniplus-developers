## O que aconteceu

A inscrição registra um único aceite para cada termo. A lista de aceites
enviada traz o mesmo termo duas ou mais vezes, e a repetição é recusada em vez
de ser descartada em silêncio, para que o comprovante registre exatamente o
que a pessoa aceitou.

## Como resolver

Envie um único aceite para cada termo. Quem integra o formulário deve montar a
lista de aceites sem duplicar o código do termo, por exemplo ao reenviar a
lista depois de uma tentativa recusada.
