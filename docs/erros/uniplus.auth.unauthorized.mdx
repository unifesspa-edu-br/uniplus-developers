## O que aconteceu

O endpoint exige autenticação, e a requisição não trouxe um token Bearer
válido — o header `Authorization` está ausente, o token está malformado,
expirou ou tem assinatura inválida.

A resposta não distingue qual dessas causas ocorreu: o corpo do erro e o
header `WWW-Authenticate: Bearer` não trazem `error`/`error_description`
detalhando o motivo da falha de validação do JWT. É decisão deliberada —
expor a causa exata de uma falha de autenticação amplia a superfície para
quem está tentando adivinhar credenciais válidas.

## Como resolver

Obtenha um token de acesso válido pelo fluxo de autenticação institucional
(Keycloak/OIDC) e inclua-o no header `Authorization: Bearer <token>` da
requisição. Se você já tinha um token, ele provavelmente expirou — autentique
novamente para obter um novo.
