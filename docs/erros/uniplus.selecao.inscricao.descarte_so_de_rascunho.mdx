## O que aconteceu

O pedido tenta descartar uma inscrição que já foi enviada. Só o rascunho se
descarta (UNI-REQ-0023): a inscrição enviada tem número e comprovante e não é
removida.

## Como resolver

Para desistir da inscrição enviada, cancele-a enquanto as inscrições estiverem
abertas (UNI-REQ-0033). Depois do cancelamento, é possível iniciar uma
inscrição nova, do zero, no mesmo processo seletivo.
