## O que aconteceu

A **composição de vagas** informada não é um dos quatro tokens do domínio
fechado: `RESIDUAL_DO_VO`, `DENTRO_DO_VR`, `RETIRA_DE` ou
`SUPLEMENTAR_AO_TOTAL`.

A composição de vagas tem valor padrão: se omitida, a modalidade assume
`RESIDUAL_DO_VO` silenciosamente. Este erro só dispara quando um token é
informado e não é um dos quatro válidos.

## Como resolver

Informe um dos quatro tokens válidos — `RESIDUAL_DO_VO`, `DENTRO_DO_VR`,
`RETIRA_DE` ou `SUPLEMENTAR_AO_TOTAL` — ou omita o campo para aceitar o
padrão `RESIDUAL_DO_VO`.
