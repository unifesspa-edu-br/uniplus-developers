## O que aconteceu

O envelope congelado que uma retificação está descartando contém dois
nós com o mesmo `noPaiId` e a mesma `ordem` entre si. É o mesmo
invariante de
[`ordem_raiz_no_exigencia_duplicada`](./uniplus.selecao.processo_seletivo.ordem_raiz_no_exigencia_duplicada.mdx),
aplicado entre irmãos em vez de entre raízes — os nós são agrupados por
pai, e cada grupo é conferido separadamente.

Na escrita normal, a ordem de cada filho também é sempre derivada da
posição no array `filhos` do nó pai — nunca dois filhos do mesmo pai
recebem a mesma ordem. Sem esta checagem no descarte, a duplicidade só
falharia depois, como violação do índice único
`ux_nos_exigencia_irmaos_ordem`.

## Como resolver

O payload que você enviou não é a causa — é a configuração congelada
para a qual o sistema está tentando voltar que já contém a duplicidade.
Abra uma investigação em vez de tentar corrigir pelo descarte.
