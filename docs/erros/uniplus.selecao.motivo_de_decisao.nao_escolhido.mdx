Este código entra com a uniplus-api#2324, que generaliza o cadastro de motivos de
decisão por tipo. Até lá, a API não o emite.

## O que aconteceu

O pedido de `DELETE /api/selecao/processos-seletivos/{id}/motivos-de-decisao/{motivoId}` indicou um motivo que não está entre os escolhidos pelo processo. A recusa sai com **404**.

## Como resolver

Confira o identificador do motivo na lista em `GET /api/selecao/processos-seletivos/{id}/motivos-de-decisao`.
