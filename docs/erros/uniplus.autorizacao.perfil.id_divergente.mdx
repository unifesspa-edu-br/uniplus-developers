## O que aconteceu

A alteração de um perfil foi enviada para o endereço de um perfil, mas o corpo da requisição traz o identificador de outro. Para não alterar o perfil errado, o sistema recusa. Nada foi alterado.

## Como resolver

Abra o perfil que você quer alterar a partir da lista e salve a partir dessa tela, que envia sempre o mesmo identificador nos dois lugares. Quem integra por programa deve enviar o identificador do perfil no endereço e no corpo, iguais.
