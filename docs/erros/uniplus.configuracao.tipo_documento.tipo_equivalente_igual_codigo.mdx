## O que aconteceu

O código informado como **tipo equivalente** é o mesmo código do próprio
tipo de documento — uma auto-referência sem sentido, já que equivalência é
uma relação entre dois tipos distintos (por exemplo, RG ≡ CIN).

A comparação é sensível a maiúsculas/minúsculas, a mesma exatidão do CHECK
correspondente no banco.

## Como resolver

Informe o código de outro tipo de documento como equivalente, ou omita o
campo se este tipo não tem equivalente declarado.
