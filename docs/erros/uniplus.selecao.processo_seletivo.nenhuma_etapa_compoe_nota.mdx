## O que aconteceu

O payload de definição de etapas tem ao menos uma etapa, mas nenhuma delas
**compõe a nota** — nenhuma é de caráter classificatória (ou ambas) **com**
peso informado (os dois juntos, não um ou outro; ver
[`etapa_processo.peso_invalido`](./uniplus.selecao.etapa_processo.peso_invalido.mdx)).

A checagem existe para blindar a fórmula da nota final
(`NOTA FINAL = Soma(Etapa × peso) / divisor`): sem ao menos uma etapa que
componha a nota, o divisor da fórmula fica zero — uma divisão por zero que a
guarda existe para nunca deixar acontecer.

**Uma lista de etapas totalmente vazia não dispara este erro** — é um estado
válido, para processos sem prova própria (ex.: SiSU, classificação
importada). A guarda só vale quando há etapas: com pelo menos uma etapa no
payload, ao menos uma precisa compor a nota.

Este código dispara em dois momentos: ao **definir etapas**
(`PUT .../etapas`) e, separadamente, ao **descartar uma retificação** — a
restauração da configuração congelada prova o grafo inteiro antes de
aplicá-lo, e valida a mesma invariante contra o envelope que está sendo
restaurado.

## Como resolver

Garanta que ao menos uma etapa do payload tenha `carater` classificatória (ou
ambas) **e** `peso` informado. Se todas as etapas do processo são
eliminatórias puras (sem compor nota), remova a lista inteira em vez de
enviar um conjunto que não sustenta a fórmula da nota final.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o descarte
está tentando voltar. Isso indica uma inconsistência na versão publicada
anterior; abra uma investigação em vez de tentar corrigir pelo descarte.
