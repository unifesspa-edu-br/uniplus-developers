## O que aconteceu

O **Id** informado não corresponde a nenhuma unidade existente — nunca
existiu, ou já foi removida (a remoção é sempre soft-delete).

Esta causa aparece apenas ao **atualizar** ou **remover** uma unidade por
Id.

## Como resolver

Confira o Id informado. Liste as unidades vigentes para localizar o Id
correto, se necessário.
