## O que aconteceu

O **tipo equivalente** informado excede o tamanho máximo aceito: 60
caracteres — o mesmo limite do código de um tipo de documento.

Tipo equivalente é um rótulo classificatório (por exemplo, RG ≡ CIN), não
um relacionamento material: guarda o código de outro tipo, sem chave
estrangeira. A integridade referencial (se o código apontado existe) não é
conferida — remover o tipo apontado como equivalente por outro não é
bloqueado, e o rótulo do outro fica simplesmente apontando para um código
sem alvo vivo.

## Como resolver

Reduza o código do tipo equivalente para até 60 caracteres.
