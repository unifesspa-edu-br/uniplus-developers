## O que aconteceu

Uma modalidade com `composicaoVagas: RETIRA_DE` declara um
`composicaoOrigemCodigo` que existe no cadastro de modalidades, mas **não
está entre as modalidades selecionadas nesta mesma oferta**. A validação de
[`modalidade_selecionada.composicao_origem_obrigatoria`](./uniplus.selecao.modalidade_selecionada.composicao_origem_obrigatoria.mdx)
só prova que o campo foi preenchido — esta checagem, separada, prova que ele
aponta para algo que de fato existe **nesta** distribuição. Uma modalidade
não pode retirar vagas de outra que a oferta nem ofereceu.

Esta checagem roda depois que todas as modalidades da distribuição já foram
criadas individualmente (todas passaram pelas checagens de forma, incluindo
`composicao_origem_obrigatoria`), sobre o conjunto delas — por isso é uma
causa de `ConfiguracaoDistribuicaoVagas`, não de `ModalidadeSelecionada`.
Verifica só a primeira modalidade do conjunto cuja referência falhar, e só a
primeira referência dessa modalidade (origem, antes de destino/par/fallback
— ver
[`remanejamento_destino_nao_selecionado`](./uniplus.selecao.configuracao_distribuicao_vagas.remanejamento_destino_nao_selecionado.mdx)).
Acumula, no mesmo array `errors[]`, com
[`configuracao_distribuicao_vagas.modalidade_duplicada`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidade_duplicada.mdx)
— a checagem irmã do mesmo bloco —, sob o campo
`distribuicaoVagas[<índice>].modalidadeIds`.

Este código também aparece no **descarte de retificação**, com a mesma
propagação de violação única (sem `errors[]`) já documentada para
`modalidade_duplicada`.

## Como resolver

Inclua a modalidade de origem em `modalidadeIds`, na mesma distribuição, ou
corrija, no cadastro de modalidades de Configuração, o código de origem
declarado para apontar a uma modalidade que de fato está sendo selecionada
nesta oferta.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
