## O que aconteceu

O identificador informado não corresponde a nenhum tipo de banca existente
— ou porque nunca existiu, ou porque já foi removido (soft delete).

A remoção nunca é bloqueada por referência — o único consumo é por
snapshot-copy desacoplado no módulo Seleção.

## Como resolver

Confira o identificador do tipo de banca. Se ele foi removido, cadastre um
novo (com o mesmo código canônico, se aplicável) ou use outro já existente.
