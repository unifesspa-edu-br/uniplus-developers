:::warning Código ainda não emitido

Este código entra com a uniplus-api#2324, que generaliza o cadastro de motivos de
decisão por tipo. Até lá, a API não o emite.

:::

## O que aconteceu

O código do motivo segue o formato `^[A-Z][A-Z0-9_]{1,49}$`: começa com letra maiúscula, continua com letras maiúsculas, dígitos ou sublinhado e tem de 2 a 50 caracteres. O código enviado em `POST /api/selecao/admin/motivos-de-decisao` não segue esse formato, por exemplo por ter letra minúscula, acento, espaço ou hífen. A recusa sai com **422**, e o erro aparece no campo `codigo`.

## Como resolver

Reescreva o código no formato aceito: `DOCUMENTO_ILEGIVEL` é aceito; `documento-ilegível` não é.
