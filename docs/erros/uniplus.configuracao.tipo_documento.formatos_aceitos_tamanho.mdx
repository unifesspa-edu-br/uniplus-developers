## O que aconteceu

O texto de **formatos aceitos** excede o tamanho máximo aceito: 200
caracteres.

Este campo é um default classificatório, sem efeito material em runtime —
a regra que de fato vale numa inscrição é a que a exigência documental do
edital congela, não a lida direto do cadastro.

## Como resolver

Reduza o texto de formatos aceitos para até 200 caracteres.
