## O que aconteceu

O sinalizador **permite complementação** (campo `permiteComplementacao`) foi
enviado como verdadeiro numa fase cujo código não é
`HOMOLOGACAO_INSCRICOES`.

A legislação permite complementação/reenvio documental só na homologação das
inscrições — a habilitação é deliberadamente excluída (o SiSU veda
complementação nessa fase). A complementação durante o recurso acontece na
fase de origem do ato recorrido, pela permissão do tipo dessa fase; não há
fase de recursos.

## Como resolver

Envie `permiteComplementacao: false`, ou — se a intenção é mesmo permitir
complementação — isso só é válido na fase de código
`HOMOLOGACAO_INSCRICOES`.
