## O que aconteceu

O sinalizador **permite complementação** foi enviado como verdadeiro numa
fase cujo código não é `HOMOLOGACAO` nem `RECURSOS`.

A legislação permite complementação/reenvio documental só nessas duas fases
— a habilitação é deliberadamente excluída (o SiSU veda complementação
nessa fase).

## Como resolver

Envie `permite_complementacao: false`, ou — se a intenção é mesmo permitir
complementação — isso só é válido nas fases de código `HOMOLOGACAO` ou
`RECURSOS`.
