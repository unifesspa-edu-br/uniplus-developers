## O que aconteceu

O **código e-MEC** da oferta excede o tamanho máximo aceito: 20 caracteres.

Este é o código e-MEC por campus-sede da oferta — o mesmo curso tem ofertas
distintas por campus, cada uma com seu próprio código e-MEC.

## Como resolver

Informe um código e-MEC com até 20 caracteres.
