## O que aconteceu

O **Id** declarado como unidade raiz da instituição não corresponde a
nenhuma unidade existente, ou foi removida.

A instituição — o registro singleton que descreve a própria IES —
declara o vínculo com sua unidade raiz (a reitoria) por Id, sem chave
estrangeira entre bancos. Sem uma unidade real para apontar, o vínculo
não pode ser estabelecido.

## Como resolver

Confira o Id informado como unidade raiz. Se a unidade foi removida,
escolha outra unidade viva do tipo reitoria. Se o problema não é a
unidade não existir, mas ela não ser do tipo correto, a causa é outra:
veja
[unidade raiz não é reitoria](./uniplus.organizacao.instituicao.unidade_raiz_nao_eh_reitoria.mdx).
