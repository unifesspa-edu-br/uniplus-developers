## O que aconteceu

O sinalizador **agrupa etapas** foi enviado como verdadeiro numa fase cujo
código não é `AVALIACAO`.

Fase canônica não é Etapa — a Etapa pontuada pertence a outro cadastro; este
sinalizador só marca qual fase as agrupa, e no vocabulário de dezesseis fases
só a de avaliação cumpre esse papel.

## Como resolver

Envie `agrupa_etapas: false`, ou — se a intenção é mesmo agrupar etapas
pontuadas — isso só é válido na fase de código `AVALIACAO`.
