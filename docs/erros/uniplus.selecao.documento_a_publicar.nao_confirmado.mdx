## O que aconteceu

O documento existe, mas o envio dele ainda não foi confirmado. Enquanto está pendente, o
arquivo no armazenamento não passou pela conferência de formato, tamanho e conteúdo e pode
ter sido substituído enquanto a URL de envio valia. Por isso a API não entrega um link de
leitura para ele.

## Como resolver

Confirme o envio do documento. Se a URL de envio já venceu sem o arquivo ter sido enviado, a
confirmação recusa com
[`objeto_nao_encontrado`](./uniplus.selecao.documento_a_publicar.objeto_nao_encontrado.mdx):
inicie um novo envio.
