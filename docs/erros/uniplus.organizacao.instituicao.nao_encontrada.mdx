## O que aconteceu

O **Id** informado não corresponde à instituição existente — nunca
existiu, ou já foi removida (a remoção é sempre soft-delete, liberando a
vaga do singleton para recadastramento).

Esta causa aparece apenas ao **atualizar** ou **remover** a instituição
por Id.

## Como resolver

Confira o Id informado. Como a instituição é singleton, consulte a
leitura pública (que não exige Id) para obter o registro vigente, se
houver algum.
