## O que aconteceu

A operação foi recusada porque o **código** do tipo de etapa não foi
preenchido.

O código é a chave natural do cadastro — único e imutável para sempre,
mesmo após o tipo ser desativado: desativar impede novos vínculos, mas não
libera o código para reuso.

## Como resolver

Informe um código para o tipo de etapa.
