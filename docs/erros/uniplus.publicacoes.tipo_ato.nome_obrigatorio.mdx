## O que aconteceu

A operação foi recusada porque o **nome** do tipo de ato não foi
informado.

Diferente do código — a identidade estável, no vocabulário
`MAIUSCULO_COM_UNDERSCORE` — o nome é a descrição legível do tipo (ex.:
"Edital de abertura", "Convocação para matrícula"), usada em exibição.
Ambos são obrigatórios: o código identifica, o nome descreve, e nenhum
supre o outro.

## Como resolver

Informe o nome do tipo de ato. Se o nome estiver presente mas fora do
tamanho aceito, a causa é outra: veja
[nome do tipo de ato excede o tamanho](./uniplus.publicacoes.tipo_ato.nome_tamanho.mdx).
