## O que aconteceu

O código informado é `*` — reservado para expressar obrigatoriedade legal
**universal** (aplicável a todo tipo de processo, não a um tipo específico),
não disponível para um cadastro de tipo de processo seletivo.

## Como resolver

Use um código diferente de `*` para o tipo de processo seletivo.
