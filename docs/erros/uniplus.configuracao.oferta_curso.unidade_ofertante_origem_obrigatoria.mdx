## O que aconteceu

O snapshot-copy da unidade ofertante — o que a oferta de curso congela da
Unidade viva no ato da criação — foi montado sem o id de origem
(`Guid.Empty`).

Esta é uma validação defensiva sobre o snapshot em si, depois que a Unidade
viva já foi lida com sucesso em Organização Institucional: na prática, ela só
dispara se algo na montagem do snapshot, a partir da leitura cross-módulo,
tiver perdido o id no caminho — não é o cliente HTTP quem informa este campo
diretamente.

## Como resolver

Esta causa aponta para uma inconsistência na montagem do snapshot a partir da
leitura da Unidade, não para um campo que o cliente da API preenche. Se
ocorrer, é sinal de defeito na integração entre os dois módulos, e não algo
corrigível ajustando a requisição.
