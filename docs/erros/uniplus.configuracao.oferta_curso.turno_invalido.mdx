## O que aconteceu

Um dos turnos informados em `turnos` não é um dos três tokens do domínio
fechado: `MATUTINO`, `VESPERTINO` ou `NOTURNO`.

`INTEGRAL` **não é turno**. Uma oferta que funciona em dois períodos declara
`regimeDeTurno: "INTEGRAL"` e nomeia os dois em `turnos` — o rótulo sozinho
não diria quais são.

O turno é obrigatório em todo formato pedagógico, a distância inclusive: não
existe oferta sem turno. Se a lista estiver ausente ou vazia, o erro é
[`turnos_obrigatorios`](uniplus.configuracao.oferta_curso.turnos_obrigatorios.mdx),
não este.

## Como resolver

Informe apenas tokens válidos em `turnos`:

```json
{
  "regimeDeTurno": "INTEGRAL",
  "turnos": ["MATUTINO", "VESPERTINO"]
}
```

A resposta devolve os turnos em ordem canônica — matutino, vespertino,
noturno — qualquer que tenha sido a ordem de envio.
