## O que aconteceu

O **turno** informado não é um dos quatro tokens do domínio fechado:
`MATUTINO`, `VESPERTINO`, `NOTURNO` ou `INTEGRAL`.

O turno é opcional — a oferta pode não declará-lo. Este erro só dispara
quando um token é informado e não é um dos quatro válidos.

## Como resolver

Informe um dos quatro tokens válidos — `MATUTINO`, `VESPERTINO`, `NOTURNO`
ou `INTEGRAL` — ou omita o campo se a oferta não tem turno fixo.
