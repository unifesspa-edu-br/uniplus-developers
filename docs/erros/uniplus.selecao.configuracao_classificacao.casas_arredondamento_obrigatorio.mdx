## O que aconteceu

A regra de cálculo declarada é `FORMULA-MEDIA-PONDERADA`, mas
`casasArredondamento` está ausente ou não é maior que zero. É a metade do
mesmo par de campos que
[`arredondamento_obrigatorio`](./uniplus.selecao.configuracao_classificacao.arredondamento_obrigatorio.mdx)
cobre para `regraArredondamentoCodigo` — as duas checagens são separadas
propositalmente, cada uma atribuída ao campo que ela reprova; um
`regraArredondamentoCodigo` válido acompanhado de `casasArredondamento`
inválido reprova só esta, não a outra.

No caminho de definição, pode coexistir com `arredondamento_obrigatorio` e
com
[`eliminacao_enem_fora_de_processo_enem`](./uniplus.selecao.processo_seletivo.eliminacao_enem_fora_de_processo_enem.mdx)
na mesma resposta (acumula, ADR-0125). Nunca coexiste com
[`arredondamento_indevido`](./uniplus.selecao.configuracao_classificacao.arredondamento_indevido.mdx),
[`casas_arredondamento_indevido`](./uniplus.selecao.configuracao_classificacao.casas_arredondamento_indevido.mdx)
nem
[`eliminacao_indevida`](./uniplus.selecao.configuracao_classificacao.eliminacao_indevida.mdx)
— pertencem ao ramo oposto (classificação importada).

No descarte de retificação, o codec só propaga ao chamador a primeira
violação acumulada internamente. `casas_arredondamento_obrigatorio` é a
última das duas checagens do ramo local — perde a prioridade para
`arredondamento_obrigatorio` e para
[`n_opcoes_invalido`](./uniplus.selecao.configuracao_classificacao.n_opcoes_invalido.mdx)
quando também se aplicam, mas vence sobre `eliminacao_enem_fora_de_processo_enem`,
conferida depois de qualquer um dos dois ramos.

## Como resolver

Informe `casasArredondamento` com um valor inteiro maior que zero sempre que
`regraCalculoCodigo` for `FORMULA-MEDIA-PONDERADA`.
