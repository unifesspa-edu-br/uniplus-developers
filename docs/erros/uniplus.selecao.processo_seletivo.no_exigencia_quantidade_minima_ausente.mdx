## O que aconteceu

O nó decodificado do envelope congelado (uma folha ou um grupo `OU`/N-de)
não declara `quantidadeMinima`, mas a reconstrução do mesmo nó — pelas
mesmas factories da escrita, `CriarFolha`/`CriarGrupo` — normaliza esse
campo ausente para o valor padrão. É esta comparação entre o nó
DECODIFICADO e o nó RECONSTRUÍDO, feita depois de cada raiz passar por
todas as checagens estruturais, que detecta a divergência: é o nó
decodificado — não o reconstruído — que é aplicado ao agregado (ADR-0110
D2), então uma configuração congelada sem `quantidadeMinima` persistiria
o campo ausente.

Sem esta causa nomeada, o problema só apareceria depois, no
`SaveChanges`, como violação da constraint
`ck_nos_exigencia_tipo_campos_coerentes` — um encoder real nunca produz
esse estado, já que sempre serializa a `quantidadeMinima` efetiva (já
normalizada) de cada nó.

## Como resolver

O payload que você enviou não é a causa — é a configuração congelada
para a qual o sistema está tentando voltar que já contém a
inconsistência. Abra uma investigação em vez de tentar corrigir pelo
descarte.
