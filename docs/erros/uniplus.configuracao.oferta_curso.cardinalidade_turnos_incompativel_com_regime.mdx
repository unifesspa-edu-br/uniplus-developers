## O que aconteceu

A quantidade de turnos informada não é a que o `regimeDeTurno` declarado exige:

| Regime declarado | Turnos exigidos |
|---|---|
| `REGULAR` | exatamente 1 |
| `INTEGRAL` | exatamente 2, distintos |

O regime é **declarado, nunca inferido**. Enviar dois turnos com
`regimeDeTurno: "REGULAR"` é recusado — a oferta não é promovida a `INTEGRAL`
por conta própria. Isso é proposital: inferir o regime pela contagem tornaria
impossível distinguir um turno informado por engano de uma oferta que
realmente funciona em dois períodos.

A mensagem do erro nomeia o regime declarado e quantos turnos ele exige.

## Como resolver

Corrija **o lado que estava errado** — pode ser o regime ou a lista.

Se a oferta realmente ocupa dois períodos, o regime é que estava errado:

```json
{
  "regimeDeTurno": "INTEGRAL",
  "turnos": ["MATUTINO", "VESPERTINO"]
}
```

Se ocupa um só, sobra turno na lista:

```json
{
  "regimeDeTurno": "REGULAR",
  "turnos": ["MATUTINO"]
}
```
