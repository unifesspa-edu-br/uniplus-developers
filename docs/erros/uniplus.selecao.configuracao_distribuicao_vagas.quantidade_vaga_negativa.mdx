## O que aconteceu

A quantidade de vagas declarada para uma modalidade — a `quantidade` de uma
retirada ou suplemento, em cada item do bloco `quadro` do payload — é
negativa.
Esta causa de domínio é conferida em três pontos independentes: logo na
criação da modalidade selecionada (a checagem mais cedo), de novo dentro da
calculadora do quadro federal (sobre as retiradas e suplementos já
resolvidos), e uma terceira vez, defensivamente, ao materializar cada linha
do quadro — nenhuma quantidade negativa deveria chegar até ali, e a
checagem existe para nunca depender só das duas anteriores.

> **Lacuna conhecida.** Hoje, uma quantidade negativa no bloco `quadro` é
> interceptada antes de qualquer um dos três pontos de domínio por uma
> regra de validação de payload equivalente
> (`quantidade.RuleFor(q => q.Quantidade).GreaterThanOrEqualTo(0)`) — a
> resposta real ao `PUT .../distribuicao-vagas` é `uniplus.validacao`, não
> esta entrada. O código de domínio descrito aqui existe e está correto,
> mas hoje só é alcançável pelo caminho de descarte de retificação — a
> reidratação do envelope lê `quantidadeDeclarada` como escalar bruto, sem
> passar pela validação de payload do comando, então um envelope congelado
> com valor negativo (só possível sob corrupção, já que o encoder nunca
> emite um) alcança a checagem de domínio na restauração. Este código
> alcança o `PUT` quando esse comando migrar para o padrão de validação
> centrada no domínio (mesma frente da ADR-0125, rastreada em
> `uniplus-api#1227`).

## Como resolver

Informe uma quantidade não-negativa para cada modalidade do bloco `quadro`.
Enquanto a lacuna acima não for corrigida, um valor negativo no
`PUT .../distribuicao-vagas` responde com `uniplus.validacao`, não com este
código — mas a correção é a mesma: ajustar a quantidade antes de reenviar.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior (ou um envelope corrompido); abra uma investigação em
vez de tentar corrigir pelo descarte.
