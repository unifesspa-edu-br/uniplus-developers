## O que aconteceu

A pessoa já tem uma concessão ativa igual: mesmo perfil, mesmo escopo. Duas concessões iguais fariam a revogação de uma não retirar o acesso.

## Como resolver

Nenhuma ação é necessária: o acesso já existe. Consulte as concessões ativas da pessoa.
