## O que aconteceu

A **base legal** da oferta excede o tamanho máximo aceito: 500 caracteres.

Este é o mesmo campo cuja ausência, para programa diferente de `REGULAR`, é
recusada pelo
[erro de base legal obrigatória](./uniplus.configuracao.oferta_curso.base_legal_obrigatoria_para_programa_nao_regular.mdx)
— aqui a causa é o tamanho excedido, não a ausência.

## Como resolver

Reduza a base legal para até 500 caracteres.
