## O que aconteceu

Uma das etapas do payload informou `ordem` menor ou igual a zero. O campo é
opcional e só controla a posição de apresentação da etapa no envelope
congelado (não entra na fórmula da nota); quando informado, precisa ser um
valor positivo.

Este código é sobre o valor de uma `ordem` isolada, não sobre repetição entre
etapas — para duas etapas com o mesmo valor de `ordem`, ver
[`processo_seletivo.ordem_etapa_duplicada`](./uniplus.selecao.processo_seletivo.ordem_etapa_duplicada.mdx).

Esta é uma das seis checagens de forma que a definição de etapas acumula
numa só passada, antes de resolver qualquer etapa contra o catálogo de tipos —
ver [`nome_obrigatorio`](./uniplus.selecao.etapa_processo.nome_obrigatorio.mdx)
para o mecanismo completo de acumulação e a ordem em que as violações
aparecem.

## Como resolver

Informe uma `ordem` positiva, ou omita o campo se a posição de apresentação
da etapa não importa. Se a resposta trouxer mais de uma violação no array
`errors[]`, corrija todas antes de reenviar.
