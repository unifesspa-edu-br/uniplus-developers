## O que aconteceu

A inscrição é identificada pelo CPF de quem se autentica. O token de acesso de
quem fez o pedido chegou sem a informação de CPF, ou com um valor que não é um
CPF válido, e a API recusa com **403** em vez de procurar ou criar uma
inscrição sem saber de quem ela é. A operação recusada não criou nem alterou
nada.

A mensagem de detalhe da resposta diz qual das duas situações ocorreu: o token
não traz o CPF, ou o CPF do token não é válido.

## Como resolver

Encerre a sessão, entre de novo no Uni+ e repita a operação. Se o erro
persistir, o problema está no cadastro da conta ou na integração com o
provedor de identidade: acione o suporte técnico do Uni+, que precisa
investigar a causa antes que a inscrição seja possível.
