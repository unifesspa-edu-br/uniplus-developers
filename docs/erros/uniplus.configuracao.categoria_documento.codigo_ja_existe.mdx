## O que aconteceu

Já existe uma categoria de documento **ativa** com o código informado. O código é único entre as categorias que não foram removidas: uma categoria removida libera o código para uma nova.

Na atualização a conferência só roda quando o código muda. Se dois cadastros usam o mesmo código ao mesmo tempo, o segundo recebe esta recusa, porque o armazenamento também garante a unicidade. Nada foi gravado.

## Como resolver

Use um código diferente. Se a categoria existente com esse código é a que você queria, altere-a em vez de criar outra.
