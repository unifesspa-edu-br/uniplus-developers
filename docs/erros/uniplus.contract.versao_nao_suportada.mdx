## O que aconteceu

O cabeçalho `Accept` não selecionou uma versão de resposta oferecida pela operação, ou não pôde ser interpretado. A resposta informa as versões disponíveis em `available_versions`.

## Como resolver

Ajuste o `Accept` para uma versão oferecida pela operação. Consulte o contrato da operação para conhecer os tipos de mídia aceitos.
