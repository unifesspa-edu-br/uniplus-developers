## O que aconteceu

Um critério de desempate com a regra `DESEMPATE-IDOSO` não informou
`idadeMinima`. Este critério prioriza, no desempate, candidatos a partir de
uma idade mínima — sem esse valor, não há corte para aplicar.

Esta checagem verifica só que o campo foi **informado**; o valor em si
precisa ser positivo — checagem separada, ver
[`idade_minima_invalida`](./uniplus.selecao.criterio_desempate.idade_minima_invalida.mdx).
Roda na montagem dos argumentos do critério, depois que a regra já foi
resolvida contra o catálogo. Não acumula com nenhuma outra violação — é a
primeira que falhar que interrompe o processamento.

## Como resolver

Informe `idadeMinima` (com um valor positivo) para todo critério com a
regra `DESEMPATE-IDOSO`.
