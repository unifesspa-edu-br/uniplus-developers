## O que aconteceu

O tipo da condição de homologação não foi informado ou não está disponível para apuração pelo sistema.

## Como resolver

Informe um tipo disponível. Atualmente, o sistema apura `RESULTADO_NO_RETORNO_DO_INEP`.
