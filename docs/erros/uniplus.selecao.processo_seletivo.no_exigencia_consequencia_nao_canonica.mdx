## O que aconteceu

O nó decodificado do envelope congelado declara `consequencia` em uma
forma que a reconstrução — pelas mesmas factories da escrita — não
reproduz identicamente; por exemplo, uma string em branco, que
`CriarGrupo` normaliza para ausente. Mesma comparação
DECODIFICADO×RECONSTRUÍDO de
[`no_exigencia_quantidade_minima_ausente`](./uniplus.selecao.processo_seletivo.no_exigencia_quantidade_minima_ausente.mdx),
agora sobre `consequencia`.

Um encoder real sempre serializa a forma já canônica — `null` quando o
nó não emite consequência própria, ou um dos quatro valores do
vocabulário fechado quando emite. Sem esta causa nomeada, uma
configuração congelada com o campo fora da forma canônica persistiria
como está, e o problema só apareceria depois em quem lê essa
consequência supondo a forma canônica.

## Como resolver

O payload que você enviou não é a causa — é a configuração congelada
para a qual o sistema está tentando voltar que já contém a
inconsistência. Abra uma investigação em vez de tentar corrigir pelo
descarte.
