## O que aconteceu

Uma fase do cronograma declara como concluinte um código de fase que nenhuma fase
deste cronograma tem.

A conclusão do ciclo recursal precisa ser alcançável dentro do próprio cronograma:
é lá que o candidato lê quando a matéria se encerra. Apontar para uma fase que não
está publicada no cronograma deixa o ciclo sem desfecho verificável.

## Como resolver

A mensagem da recusa mostra o código declarado. Compare-o com os códigos das fases
que estão no cronograma — a comparação diferencia maiúsculas de minúsculas, então
grafia divergente já é suficiente para não encontrar a fase.

Três desfechos possíveis:

- **Erro de grafia.** Corrija o código para o da fase que de fato conclui o ciclo.
- **A fase que conclui ainda não foi incluída.** Acrescente-a ao cronograma, com o
  resultado definitivo entre os produtos que ela publica.
- **A conclusão é da própria fase.** Remova a declaração e acrescente o resultado
  definitivo aos produtos dela.
