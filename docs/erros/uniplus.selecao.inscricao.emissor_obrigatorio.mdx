## O que aconteceu

Ao iniciar a inscrição, o Uni+ guarda quem emitiu o token da conta. O token de
acesso de quem fez o pedido chegou sem a informação do emissor, e a API recusa
com **403**. Nada foi criado.

## Como resolver

Encerre a sessão, entre de novo no Uni+ e inicie a inscrição outra vez. Se o
erro persistir, o problema está na integração com o provedor de identidade:
acione o suporte técnico do Uni+, que precisa investigar a causa antes que a
inscrição seja possível.
