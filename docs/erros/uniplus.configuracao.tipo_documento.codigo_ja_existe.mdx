## O que aconteceu

Já existe um tipo de documento **vivo** com o código informado.

O código é editável — diferente de modalidade de concorrência —, então esta
checagem também roda na atualização, mas só quando o código efetivamente
muda: reenviar o mesmo código do próprio registro na atualização não
dispara este erro. A checagem cobre tanto o caminho comum quanto a corrida
entre duas operações concorrentes com o mesmo código: o índice único
parcial do banco garante a exclusividade, e uma violação nele é traduzida
para este mesmo erro.

## Como resolver

Use um código diferente.
