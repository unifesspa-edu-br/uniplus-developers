## O que aconteceu

O fato informado no endereço do pedido não aceita opções declaradas pelo
processo. Isso acontece em dois casos:

- o fato não é categórico com a fonte dos valores no processo, como são as
  edições do ENEM aceitas. Os valores dos demais fatos vêm de outra origem, como
  o catálogo, as modalidades ofertadas, os municípios do bônus regional ou as
  unidades federativas, e o processo não os redefine por aqui. O mesmo vale
  para um código de fato que o catálogo não conhece;
- o fato é um agregado sobre um grupo repetível. As opções dele são as do fato
  de cada membro do grupo, e é nesse fato que elas se declaram.

A mensagem de detalhe diz qual dos dois casos ocorreu e, no segundo, qual é o
fato do agregado. Nada foi gravado.

## Como resolver

Confira o código do fato no endereço do pedido. No caso do agregado, declare as
opções no fato de membro. Se o fato tem outra origem, as opções do processo não
se aplicam a ele.
