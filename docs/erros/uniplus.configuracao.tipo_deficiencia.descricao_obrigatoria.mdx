## O que aconteceu

A operação foi recusada porque a **descrição** do tipo de deficiência não
foi preenchida.

Diferente de outros cadastros de tipo do módulo (onde descrição costuma ser
opcional), aqui ela é obrigatória: serve também como a descrição por valor
exigida para o fato `TIPO_DEFICIENCIA` do vocabulário de fatos do
candidato.

## Como resolver

Informe uma descrição para o tipo de deficiência.
