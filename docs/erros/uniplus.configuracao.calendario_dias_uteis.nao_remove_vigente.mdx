## O que aconteceu

A operação tentou remover um dataset de calendário de dias úteis que está
**vigente**.

Remover o vigente deixaria, no instante seguinte, nenhum calendário corrente
— o que reabriria a mesma recusa de
[calendário vigente ausente](./uniplus.selecao.processo_seletivo.calendario_vigente_ausente.mdx)
para qualquer publicação de processo seletivo que dependa de contagem em dia
útil. Trocar de dataset vigente é uma operação explícita e distinta (marcar
outro dataset como vigente), nunca um efeito colateral automático de remover
o atual.

## Como resolver

Marque outro dataset como vigente antes de remover este. Se não há outro
dataset pronto, crie um novo e marque-o vigente primeiro.
