## O que aconteceu

O código informado respeita o formato (`^[A-Z_]+$`), mas não é um dos
quatorze códigos do conjunto canônico:

`INSCRICAO`, `HOMOLOGACAO`, `ENSALAMENTO`, `AVALIACAO`, `CLASSIFICACAO`,
`RESULTADO_PRELIMINAR`, `RECURSOS`, `RESULTADO_FINAL`, `HABILITACAO`,
`HETEROIDENTIFICACAO`, `MATRICULA`, `HOMOLOGACAO_RESULTADO_FINAL`,
`LISTA_ESPERA`, `CHAMADA`.

O cadastro é 100% administrado (sem seed) — os valores reais das quatorze
fases são populados via endpoint admin, ato operacional pós-deploy — mas o
próprio conjunto de códigos aceitos é fixo em código, não configurável.

## Como resolver

Use um dos quatorze códigos do conjunto canônico listados acima.
