## O que aconteceu

O código informado respeita o formato (`^[A-Z_]+$`), mas não é um dos
dezesseis códigos do conjunto canônico:

`INSCRICAO`, `SOLICITACAO_ISENCAO`, `HOMOLOGACAO`, `ENSALAMENTO`,
`AVALIACAO`, `CLASSIFICACAO`, `RESULTADO_PRELIMINAR`, `RECURSOS`,
`RESULTADO_FINAL`, `HETEROIDENTIFICACAO`, `AVALIACAO_BIOPSICOSSOCIAL`,
`HABILITACAO`, `MATRICULA`, `HOMOLOGACAO_RESULTADO_FINAL`, `LISTA_ESPERA`,
`CHAMADA`.

As dezesseis fases estruturais nascem por migration (seed institucional); a
composição do certame com elas — e os demais atributos administráveis de
cada uma (nome, descrição, base legal) — segue por CRUD. O próprio conjunto
de códigos aceitos é fixo em código, não configurável.

## Como resolver

Use um dos dezesseis códigos do conjunto canônico listados acima.
