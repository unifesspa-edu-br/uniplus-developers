## O que aconteceu

O pedido de `POST /api/selecao/admin/motivos-de-decisao/{id}/ativacao` chegou para um motivo que já está ativo, e nada foi alterado. A recusa sai com **422**.

## Como resolver

Nenhuma ação é necessária: o motivo já entra em novas escolhas dos processos. Releia o motivo para conferir a situação.
