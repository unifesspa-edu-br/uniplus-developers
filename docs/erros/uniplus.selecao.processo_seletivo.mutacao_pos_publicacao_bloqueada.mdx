## O que aconteceu

Um comando de configuração (`Definir*` — etapas, cotas, cronograma,
documentos exigidos, e todos os demais) foi enviado contra um processo que já
está **publicado e sem retificação em curso**. A configuração congelada na
publicação (UNI-REQ-0019) é imutável por construção: nenhum comando de configuração
grava sobre ela diretamente.

Este guard é verificado duas vezes por desenho — uma vez no handler, logo
após resolver o processo (a precondição precede a regra de negócio, ADR-0110
D9), e de novo dentro do próprio domínio, como invariante que não depende de
o handler lembrar de checar antes.

## Como resolver

Para alterar a configuração de um processo já publicado, abra uma
**retificação** (`POST .../retificacao-em-curso`) antes de enviar os
comandos `Definir*` — durante uma retificação em curso, os mesmos comandos
passam a alterar a configuração do processo diretamente (não há rascunho em
staging: a versão já congelada permanece intocada até o fechamento). Feche a
retificação para congelar a nova versão; descarte a retificação para
restaurar a configuração publicada, se as alterações não devem valer.

Se o processo ainda não foi publicado, o comando deveria ter funcionado —
confirme o `id` enviado; um `id` de outro processo, já publicado, produz este
mesmo erro.
