## O que aconteceu

O pedido tentou declarar, no processo, as opções de um fato cujas opções vêm do atendimento especializado: a condição de atendimento, o recurso de acessibilidade ou o tipo de deficiência. Quem responde por essas opções é o que o processo define no atendimento especializado; declarar uma lista à parte criaria uma segunda, que poderia divergir da primeira, e por isso a API recusa. A recusa sai com **422**, e nada foi gravado.

## Como resolver

Não declare opções para esses fatos. Para mudar as condições, os recursos ou os tipos de deficiência que aparecem como escolha, defina o atendimento especializado do processo (`PUT /api/selecao/processos-seletivos/{id}/atendimento-especializado`).
