## O que aconteceu

A finalidade declarada limita o formato. O documento principal do edital é publicado como
está e só pode ser PDF; anexo do edital e documento de ato aceitam PDF, DOCX ou ODT. A
recusa vem quando o formato informado não é aceito pela finalidade, hoje o DOCX ou o ODT
declarados como documento do edital.

## Como resolver

Para o documento principal do edital, exporte o arquivo para PDF. Se o arquivo é um
complemento do edital, declare a finalidade `anexoDoEdital`. Repita o início do envio.
