## O que aconteceu

O campo `regimeDeTurno` não foi informado. Ele é obrigatório e não tem valor
padrão: nenhuma oferta funciona sem declarar se ocupa um turno ou dois.

Informar um token fora do domínio é outro erro —
[`regime_de_turno_invalido`](uniplus.configuracao.oferta_curso.regime_de_turno_invalido.mdx).
A distinção é proposital: quem não informou nada precisa de orientação
diferente de quem informou o token errado.

## Como resolver

Declare o regime junto com os turnos correspondentes:

```json
{
  "regimeDeTurno": "REGULAR",
  "turnos": ["NOTURNO"]
}
```

- `REGULAR` — a oferta funciona em **um** turno.
- `INTEGRAL` — a oferta funciona em **dois** turnos distintos.
