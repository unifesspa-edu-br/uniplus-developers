## O que aconteceu

Já existe uma **unidade viva** (não removida) com o mesmo código.

O código é único entre unidades vivas — nunca entre todas as que já
existiram: uma unidade removida (soft-delete) libera o código para reuso.
Diferente da sigla, a comparação do código é **sensível a caixa**: `ABC`
e `abc` contam como códigos diferentes, e alterar só a caixa de um código
existente dispara esta checagem como uma mudança real. Por ser conflito
com o estado já gravado, o status é **409**, não 422.

Na atualização, esta checagem só roda quando o código efetivamente muda.

## Como resolver

Escolha um código diferente, ou verifique se a unidade que já o possui
deveria ter sido removida.
