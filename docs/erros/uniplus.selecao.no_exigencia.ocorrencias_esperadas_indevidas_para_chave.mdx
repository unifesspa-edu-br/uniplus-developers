## O que aconteceu

O campo `ocorrenciasEsperadas` de um nó folha foi informado, mas a
`chaveDistincao` do nó não é `OCORRENCIA`. Cobre dois cenários:

- `chaveDistincao` está **ausente** — sem qualificação, não há slots
  esperados a declarar.
- `chaveDistincao` é uma chave de calendário
  (`COMPETENCIA_MENSAL`/`EXERCICIO_ANUAL`) — essas chaves derivam os
  slots a partir de
  [`dataReferencia`](./uniplus.selecao.no_exigencia.data_referencia_indevida_para_chave.mdx),
  não de uma lista congelada.

Só `OCORRENCIA` usa `ocorrenciasEsperadas`, e mesmo assim como campo
opcional — presente, exige slots concretos (cada um é uma apresentação
obrigatória); ausente, cai em distinção pura (bastam N apresentações
diferentes, sem exigir quais). Sequencial: a primeira violação
encontrada na criação do nó interrompe o processamento; nunca acumula
com nenhuma outra causa desta série.

Alcançável tanto na definição quanto no descarte de retificação: o
envelope congelado lê `ocorrenciasEsperadas` como array cru, sem cruzar
com a `chaveDistincao` do mesmo nó — essa coerência só é conferida
quando o nó é reconstruído para validar invariantes.

## Como resolver

Remova `ocorrenciasEsperadas` se `chaveDistincao` estiver ausente ou for
uma chave de calendário. Se a intenção era declarar uma lista fixa de
ocorrências esperadas, informe `chaveDistincao` como `OCORRENCIA`.
