## O que aconteceu

O mesmo código aparece mais de uma vez em `conceitosAdmitidos`. A lista é um conjunto: cada conceito é admitido ou não, e repeti-lo não tem efeito. Nada foi gravado.

Na atualização, esta conferência vem antes de o tipo de etapa ser procurado: com o conteúdo nessa condição a resposta é esta, mesmo que o identificador não exista. O [404 de tipo de etapa não encontrado](./uniplus.configuracao.tipo_etapa.nao_encontrado.mdx) só prevalece quando os campos e os conceitos admitidos são válidos.

## Como resolver

Remova as repetições de `conceitosAdmitidos`, deixando cada código uma única vez.
