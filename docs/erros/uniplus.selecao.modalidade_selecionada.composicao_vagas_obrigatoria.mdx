## O que aconteceu

Uma modalidade selecionada não declarou `composicaoVagas`. A composição de
vagas decide como a modalidade entra na aritmética do quadro de vagas —
ampla concorrência residual, sub-reserva da Lei 12.711, retirada de outra
modalidade (`RETIRA_DE`, ver
[`composicao_origem_obrigatoria`](./uniplus.selecao.modalidade_selecionada.composicao_origem_obrigatoria.mdx)),
ou suplemento ao total publicado. Roda antes das checagens de coerência de
`RETIRA_DE` — sem uma composição declarada, não há como avaliar se o código
de origem é coerente com ela.

**`composicaoVagas` não vem do payload da definição de distribuição de
vagas** — é copiada do cadastro de modalidades de Configuração, no momento
em que a modalidade é selecionada (`IModalidadeReader`). O cadastro nunca
grava uma modalidade sem esse campo — quando ele é omitido no cadastro, um
valor padrão (`RESIDUAL_DO_VO`) é aplicado; não existe modalidade cadastrada
com composição de vagas literalmente vazia. O que dispara este código, na
prática, é o token de composição do cadastro **não ser reconhecido** pelo
vocabulário do módulo Seleção — hoje os dois vocabulários coincidem, então
o cenário real é uma divergência futura entre eles (o cadastro evoluindo
antes deste módulo), não um dado corrompido.

Não acumula com nenhuma outra violação — é a primeira que falhar que
interrompe a criação da modalidade.

Este código também aparece no **descarte de retificação**: reconstruir o
grafo a partir do envelope congelado recria cada modalidade selecionada a
partir dos mesmos campos — a mesma checagem roda de novo, sozinha.

## Como resolver

O campo não está no payload que você enviou — está na modalidade cadastrada
em Configuração. Confira lá a composição de vagas cadastrada; se ela
parecer correta e o erro persistir, é sinal de que o token que o cadastro
emite não é mais reconhecido pelo módulo Seleção — um problema de
sincronização entre os dois vocabulários, não de dado ausente.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
