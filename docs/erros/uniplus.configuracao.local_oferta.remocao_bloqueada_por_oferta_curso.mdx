## O que aconteceu

O local de oferta que a operação tentou remover é referenciado por pelo
menos uma **oferta de curso** viva — integridade do vínculo intra-banco
entre os dois cadastros.

## Como resolver

Remova as ofertas de curso vinculadas antes de remover este local de
oferta — o local de uma oferta de curso é imutável, então não é possível
apenas realocar a oferta para outro local sem recriá-la.
