## O que aconteceu

Perfis de gestor de acessos e de encarregada de dados valem para a instituição, sem unidade; os demais perfis valem para uma unidade, que precisa ser informada.

## Como resolver

Informe a unidade, ou nenhuma unidade no caso dos perfis de governança.
