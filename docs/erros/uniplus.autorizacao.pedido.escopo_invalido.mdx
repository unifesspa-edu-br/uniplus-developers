## O que aconteceu

O escopo do pedido segue o alcance das permissões do perfil. Perfil cujas permissões valem por unidade se pede para uma unidade, que precisa ser informada. Perfil cujas permissões valem para a instituição inteira, como os de gestor de acessos e de encarregado(a) pelo tratamento de dados, se pede sem unidade.

## Como resolver

Confira na lista de perfis o escopo do perfil escolhido: informe a unidade quando o escopo for de unidade, e nenhuma unidade quando for da instituição.
