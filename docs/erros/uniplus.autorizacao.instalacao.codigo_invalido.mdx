## O que aconteceu

O código não foi aceito. A resposta é a mesma em todos os casos, para não revelar se há instalação pendente: código errado, código vencido, instalação cancelada ou nenhuma instalação aguardando código de quem pede. Depois de cinco tentativas erradas ou passadas duas horas do envio, a instalação deixa de valer.

## Como resolver

Confira o código recebido no e-mail institucional. Se passou o prazo ou as tentativas se esgotaram, inicie a instalação de novo.
