## O que aconteceu

O perfil não se edita: toda mudança é uma versão nova. A versão proposta acrescenta uma permissão que alcança dado pessoal ou sensível a um perfil que tem concessão ativa, e isso daria esse acesso, sem nova aprovação, a quem já tem o perfil. Por enquanto, a API recusa essa ampliação, ao criar a versão ou quando ela entraria em vigor.

## Como resolver

Para dar a permissão hoje, crie um perfil novo com ela e peça a concessão desse perfil pelo fluxo de pedido, que passa pela proteção de dados. Se a mudança for só de nome, descrição, documento ou de remoção de permissão, proponha a versão sem acrescentar a permissão pessoal ou sensível.
