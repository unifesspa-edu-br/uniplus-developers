## O que aconteceu

O **código** do tipo de ato não segue o formato exigido: letras maiúsculas
sem acento, separadas por underscore (ex.: `EDITAL_ABERTURA`).

A caixa alta é **exigida, não imposta**: um código enviado em minúsculas
(`edital_abertura`) é recusado em vez de convertido em silêncio para
maiúsculas. Isso é deliberado — a coluna que guarda o código é comparada de
forma sensível a caixa pelo banco, e normalizar a caixa silenciosamente
esconderia do cliente que dois códigos que ele considerava distintos são,
na prática, o mesmo.

## Como resolver

Reescreva o código só com letras maiúsculas de A a Z (sem acento, sem
outro caractere), com palavras separadas por um único underscore — nunca
começando, terminando ou duplicando o separador. Se o código está em
minúsculas, converta antes de enviar; o servidor não faz essa conversão
por você.
