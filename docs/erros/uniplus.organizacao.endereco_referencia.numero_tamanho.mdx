## O que aconteceu

O **número** informado excede 20 caracteres, o tamanho máximo aceito.

O campo é texto, não numérico puro — aceita valores como "S/N" ou
"123-A" —, mas ainda assim limitado, já que um número de endereço real
nunca se aproxima desse tamanho.

Esta validação é compartilhada pelo mesmo value object
(`ReferenciaEnderecoGeo`, no Kernel) que valida o endereço de três
cadastros distintos, em dois módulos: a sede da Instituição (Organização
Institucional), o Campus e o Local de Oferta (Configuração). O código
desta página é o que a API hoje emite para os três — a resolução do
`type` segue a chave interna do validador compartilhado, comum aos três
cadastros, e não distingue de qual módulo a chamada partiu.

## Como resolver

Informe o número dentro do limite de 20 caracteres.
