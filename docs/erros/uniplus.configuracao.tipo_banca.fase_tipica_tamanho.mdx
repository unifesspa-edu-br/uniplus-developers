## O que aconteceu

O texto de **fase típica** excede o tamanho máximo aceito: 60 caracteres.

Este campo é um rótulo orientativo — a fase em que a banca usualmente atua
—, **não** uma referência para o cadastro de fase canônica: pode ficar
nulo e pode conter um valor que não corresponda a nenhuma fase cadastrada,
sem que isso seja conferido.

## Como resolver

Reduza o texto de fase típica para até 60 caracteres.
