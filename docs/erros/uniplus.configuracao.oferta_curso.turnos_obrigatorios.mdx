## O que aconteceu

O campo `turnos` veio ausente, nulo ou como lista vazia.

**Nenhum formato pedagógico abre exceção.** A oferta a distância (`EAD`) e a
semipresencial declaram turno como a presencial — a decisão institucional é
que o curso funciona em períodos específicos, independentemente de onde a aula
acontece. Não existe caminho na API que aceite uma oferta sem turno.

## Como resolver

Informe os turnos conforme o regime declarado:

```json
{
  "formatoPedagogico": "EAD",
  "regimeDeTurno": "REGULAR",
  "turnos": ["NOTURNO"]
}
```

Quantos turnos informar depende do `regimeDeTurno`: um sob `REGULAR`, dois
distintos sob `INTEGRAL`. Enviar quantidade diferente da exigida é
[`cardinalidade_turnos_incompativel_com_regime`](uniplus.configuracao.oferta_curso.cardinalidade_turnos_incompativel_com_regime.mdx).
