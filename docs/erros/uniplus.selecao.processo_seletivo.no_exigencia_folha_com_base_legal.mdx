## O que aconteceu

O nó decodificado do envelope congelado é uma folha, mas carrega uma ou
mais entradas de `basesLegais` — campo exclusivo de grupo `OU`/N-de com
consequência própria
([`base_legal_proibida_em_grupo_e`](./uniplus.selecao.no_exigencia.base_legal_proibida_em_grupo_e.mdx)
e
[`base_legal_sem_consequencia`](./uniplus.selecao.no_exigencia.base_legal_sem_consequencia.mdx)
já cobrem as duas outras formas de base legal indevida, ambas em nó
grupo). `CriarFolha` nem tem parâmetro para base legal própria: uma
folha nunca a carrega na escrita normal, e a comparação
DECODIFICADO×RECONSTRUÍDO (ver
[`no_exigencia_quantidade_minima_ausente`](./uniplus.selecao.processo_seletivo.no_exigencia_quantidade_minima_ausente.mdx))
não pega este caso — a reconstrução de uma folha simplesmente IGNORA o
campo, em vez de recusar, porque ele nem é parâmetro de `CriarFolha`.
Por isso esta causa é uma checagem própria sobre o nó decodificado, não
uma comparação com a reconstrução.

Sem esta causa nomeada, o problema só apareceria depois, no
`SaveChanges`, ao tentar persistir uma base legal vinculada a uma folha
que a API de escrita normal nunca produz.

## Como resolver

O payload que você enviou não é a causa — é a configuração congelada
para a qual o sistema está tentando voltar que já contém a
inconsistência. Abra uma investigação em vez de tentar corrigir pelo
descarte.
