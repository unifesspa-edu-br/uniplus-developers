## O que aconteceu

Um campo não pertence ao formato do documento. A causa aponta o caminho do campo.

Na resposta HTTP, essa causa acompanha o código principal `uniplus.selecao.documento_da_configuracao.forma_invalida`.

## Como resolver

Remova o campo ou consulte o formato suportado para usar o nome correto.
