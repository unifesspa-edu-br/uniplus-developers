## O que aconteceu

A operação foi recusada porque o **código** do tipo de documento não foi
preenchido.

O código é a chave natural do cadastro — único entre tipos vivos —, mas,
diferente do código de modalidade de concorrência, é **editável**: o
consumo cross-módulo é por snapshot-copy desacoplado, então editar o código
de um tipo vivo não altera o rótulo já congelado numa exigência documental
existente.

## Como resolver

Informe um código para o tipo de documento.
