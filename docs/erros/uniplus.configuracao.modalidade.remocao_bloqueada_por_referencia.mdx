## O que aconteceu

A modalidade que a operação tentou remover é referenciada por outra
modalidade **viva** — como código de origem de uma composição `RETIRA_DE`,
ou como destino, par ou fallback de remanejamento.

Removê-la deixaria a modalidade que referencia apontando para um código
inexistente. A checagem exclui a própria modalidade — uma modalidade que
referencia a si mesma não bloqueia a própria remoção por essa causa.

## Como resolver

Atualize (ou remova) primeiro a modalidade que faz a referência, para que
ela deixe de apontar para esta — só então remova esta.
