## O que aconteceu

O leiaute (código e versão) não existe no catálogo, foi desativado ou é de outro tipo: o leiaute de envio não serve para importar o retorno, e o de retorno não serve para gerar o envio.

## Como resolver

Consulte o catálogo de leiautes ativos e escolha um do tipo certo para a operação: envio para gerar o arquivo ao INEP, retorno para importar as notas.
