## O que aconteceu

O **Id** declarado como unidade superior na hierarquia não corresponde a
nenhuma unidade existente.

A hierarquia organizacional é auto-referencial: cada unidade pode
declarar uma unidade superior, formando a árvore que vai da reitoria aos
núcleos. A unidade superior é opcional — só a reitoria, no topo, tipicamente
não declara nenhuma — mas quando informada, precisa apontar para uma
unidade real.

## Como resolver

Confira o Id informado como unidade superior. Se a unidade superior foi
removida, escolha outra unidade viva na hierarquia, ou deixe o campo
ausente se esta for a unidade de topo.
