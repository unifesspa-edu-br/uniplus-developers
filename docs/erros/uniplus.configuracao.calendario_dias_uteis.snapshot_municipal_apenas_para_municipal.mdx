## O que aconteceu

Um dos dias não úteis trouxe código IBGE, nome ou UF de município mesmo com
abrangência diferente de `MUNICIPAL`.

O snapshot de município é o par (código IBGE, nome, UF) que ancora um feriado
municipal a uma cidade específica. Ele só faz sentido quando a abrangência é
`MUNICIPAL` — em `NACIONAL`, `ESTADUAL` ou `INSTITUCIONAL`, informar qualquer
um dos três campos é recusado, mesmo que os outros dois estejam ausentes.

## Como resolver

Se a abrangência do dia é `MUNICIPAL`, mantenha o snapshot de município. Caso
contrário, remova código IBGE, nome e UF do município desse item — nenhum dos
três se aplica.
