## O que aconteceu

O mesmo documento consta mais de uma vez no ato: em dois anexos, ou como principal e como
anexo. Cada arquivo publicado do ato tem um lugar só.

## Como resolver

Mantenha cada documento uma única vez. Se são arquivos diferentes, envie cada um e use o
identificador próprio.
