## O que aconteceu

A operação foi recusada porque o **código** do tipo de deficiência não foi
preenchido.

O código (ex.: `DEFICIENCIA_VISUAL`, `TEA`, `SURDOCEGUEIRA`) é a identidade
semântica do cadastro: é ele que os fatos de atendimento congelam junto com
a origem, e é por ele que a solicitação é resolvida depois. O nome continua
sendo o rótulo legível, e também é único entre tipos vivos, mas não faz as
vezes de identidade.

O código é informado por quem cadastra — o sistema não o gera a partir do
nome.

## Como resolver

Informe um código para o tipo de deficiência.
