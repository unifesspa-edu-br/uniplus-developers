## O que aconteceu

Um dos produtos que a fase declara publicar cita um tipo de ato que não tem versão
vigente no catálogo de tipos de ato publicados na data de hoje. Ou o código não
existe no catálogo, ou existe e nenhuma versão dele está vigente agora.

A fase não descreve o documento que vai publicar por texto livre: ela referencia um
tipo de ato do catálogo, que é o que fixa o modelo, os campos e a classificação
daquela publicação. Referenciar um tipo sem versão vigente deixaria a fase apontando
para um modelo que ninguém consegue emitir.

## Como resolver

A mensagem da recusa nomeia o código declarado, e o campo indica qual produto de
qual fase o trouxe. Três desfechos possíveis:

- **Erro de grafia no código.** Corrija para o código exato do catálogo.
- **O tipo existe e está sem versão vigente.** Publique a versão dele no catálogo de
  tipos de ato, no módulo Publicações, e repita a definição do cronograma.
- **O tipo não é o certo.** Declare o tipo de ato que a fase de fato publica.
