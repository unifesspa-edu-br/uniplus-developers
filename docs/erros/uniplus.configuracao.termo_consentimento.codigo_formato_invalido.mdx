## O que aconteceu

O nome informado não gera um código válido para o termo. Após a normalização, o código deve começar por letra de A a Z e ter de 2 a 100 caracteres, com letras, dígitos e sublinhado.

## Como resolver

Escolha um nome que forme um código nesse formato.
