## O que aconteceu

O **código** do tipo de processo seletivo excede o tamanho máximo aceito: 64
caracteres.

Diferente de outros cadastros de vocabulário fechado do módulo (como
modalidade e fase canônica), o código do tipo de processo não segue um
formato UPPER_SNAKE restrito — aceita qualquer caractere, exceto o caractere
nulo (ver
[código com caractere nulo](./uniplus.configuracao.tipo_processo.codigo_com_caractere_nulo.mdx)).
Isso é sobre o conjunto de caracteres aceitos, não sobre todo valor: o
código `*` é recusado por inteiro, reservado a outro propósito (ver
[código reservado](./uniplus.configuracao.tipo_processo.codigo_reservado.mdx)).

## Como resolver

Reduza o código para até 64 caracteres.
