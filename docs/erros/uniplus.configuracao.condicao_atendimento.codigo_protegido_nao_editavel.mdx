## O que aconteceu

A operação tentou alterar o código de uma condição cujo código atual é
`PCD` — o único código reservado deste cadastro (ADR-0067) — para um código
diferente.

Diferente de modalidade e fase canônica, este cadastro não tem um conjunto
fixo de códigos protegidos semeados: `PCD` só se torna protegida depois de
existir uma condição viva com esse código, criada normalmente pelo
cadastro. A partir daí, renomear essa condição para outro código é
recusado — editar nome e descrição mantendo o código `PCD` continua
permitido.

## Como resolver

Não é possível trocar o código de uma condição `PCD` por outro. Envie a
atualização mantendo o código `PCD`, ou crie uma condição nova com o código
desejado.
