## O que aconteceu

O **tipo** da unidade não corresponde a um dos valores válidos, ou é o
valor sentinela `Nenhum` (usado internamente para detectar corrupção de
dado, nunca um tipo aceitável na entrada).

O tipo classifica a unidade na hierarquia institucional — reitoria,
pró-reitoria, centro, instituto, faculdade, departamento, coordenação,
diretoria, divisão, núcleo ou outro. É um roster fechado: acrescentar um
tipo novo exige deliberação, não é algo que a entrada da API decida.

## Como resolver

Informe um dos tipos de unidade válidos. Se o tipo que você precisa não
existe na lista atual, a solicitação de um tipo novo é decisão de
governança institucional, não algo resolvível ajustando a requisição.
