## O que aconteceu

O tipo de etapa chegou sem a declaração dos conceitos admitidos: o campo `conceitosAdmitidos` veio ausente ou nulo. A declaração é obrigatória para que fique explícito que a lista não foi esquecida. Uma lista **vazia** é válida e significa que o tipo de etapa não admite nenhum conceito. Na atualização o campo também precisa ser enviado, porque a lista é substituída por inteiro. Nada foi gravado.

Na atualização, esta conferência vem antes de o tipo de etapa ser procurado: com o conteúdo nessa condição a resposta é esta, mesmo que o identificador não exista. O [404 de tipo de etapa não encontrado](./uniplus.configuracao.tipo_etapa.nao_encontrado.mdx) só prevalece quando os campos e os conceitos admitidos são válidos.

## Como resolver

Envie `conceitosAdmitidos` com os códigos dos tipos de conceito admitidos, ou com `[]` se o tipo de etapa não admite nenhum.
