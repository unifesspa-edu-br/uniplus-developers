## O que aconteceu

O mesmo turno aparece mais de uma vez em `turnos` — por exemplo,
`["MATUTINO", "MATUTINO"]`.

Um curso integral ocupa **dois períodos diferentes** do dia. Repetir o mesmo
turno não descreve uma oferta integral; descreve uma oferta de um turno só,
informada duas vezes.

## Como resolver

Se a oferta ocupa dois períodos, nomeie os dois:

```json
{
  "regimeDeTurno": "INTEGRAL",
  "turnos": ["MATUTINO", "VESPERTINO"]
}
```

Se ocupa apenas um, declare o regime correspondente:

```json
{
  "regimeDeTurno": "REGULAR",
  "turnos": ["MATUTINO"]
}
```
