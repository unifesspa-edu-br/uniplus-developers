## O que aconteceu

O **código de origem** (`composicao_origem`) foi informado mesmo com
composição de vagas diferente de `RETIRA_DE`.

A equivalência entre composição e origem é exata nos dois sentidos:
`RETIRA_DE` exige origem (ver
[origem obrigatória para RETIRA_DE](./uniplus.configuracao.modalidade.origem_obrigatoria_para_retira_de.mdx)),
e qualquer outra composição a proíbe.

## Como resolver

Remova o código de origem, ou troque a composição de vagas para `RETIRA_DE`
se a intenção é que esta modalidade retire vagas de outra.
