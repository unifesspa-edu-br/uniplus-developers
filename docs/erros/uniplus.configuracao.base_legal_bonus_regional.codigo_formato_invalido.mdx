## O que aconteceu

A identificação do instrumento, após a normalização usada para formar o código da base legal, não contém letras de A a Z nem dígitos. O código é formado pelo tipo do instrumento e pela identificação.

## Como resolver

Informe uma identificação que, após a normalização, contenha ao menos uma letra de A a Z ou um dígito.
