## O que aconteceu

A lista `itensDeAvaliacao` da etapa trouxe o mesmo `id` em dois itens. O id identifica um
item que já existe, e é por ele que a gravação preserva o vínculo de quem aponta para o
critério; dois itens com o mesmo id disputariam a mesma linha.

A recusa vale já na gravação, também em rascunho, e chega no array `errors[]`, no campo
`itensDeAvaliacao[i].id` do segundo item.

## Como resolver

Mantenha o `id` em um só item. O item novo é enviado sem `id`.

Se a resposta trouxer mais de uma violação em `errors[]`, corrija todas antes de
reenviar.
