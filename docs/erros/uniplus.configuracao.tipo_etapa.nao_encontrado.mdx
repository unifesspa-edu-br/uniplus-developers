## O que aconteceu

O identificador informado não corresponde a nenhum tipo de etapa
existente.

Diferente de outros cadastros do módulo, o tipo de etapa nunca é removido —
só desativado. Um tipo desativado ainda é encontrado por este
identificador; esta causa é exclusivamente de identificador inexistente.

## Como resolver

Confira o identificador do tipo de etapa.
