## O que aconteceu

O identificador informado não corresponde a nenhum tipo de etapa
existente.

Um tipo de etapa removido também não é encontrado pela consulta por este
identificador: a API só traz os tipos que estão em circulação. Tentar remover
de novo um tipo já removido não cai aqui, mas na recusa
[`ja_desativado`](./uniplus.configuracao.tipo_etapa.ja_desativado.mdx).

## Como resolver

Confira o identificador do tipo de etapa e, se ele já existiu, se o tipo não
foi removido.
