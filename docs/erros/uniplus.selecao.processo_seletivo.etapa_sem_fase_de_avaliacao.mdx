## O que aconteceu

Na configuração congelada de uma versão publicada há uma etapa pontuada que não declara a
fase em que acontece, e nenhuma fase do cronograma agrupa etapas. A recusa sai com
**422**.

A situação não nasce do que se envia. Uma versão publicada já exige que toda
etapa declare a fase em que acontece
([`etapa_sem_fase_declarada`](./uniplus.selecao.processo_seletivo.etapa_sem_fase_declarada.mdx)),
então este código indica inconsistência na versão publicada.

## Como resolver

Não há correção pelo pedido enviado. Abra uma investigação sobre a versão
publicada, em vez de tentar corrigir pelo pedido.
