## O que aconteceu

O documento declara um formato ou uma versão que esta versão do sistema não suporta.

Na resposta HTTP, essa causa acompanha o código principal `uniplus.selecao.documento_da_configuracao.forma_invalida`.

## Como resolver

Use um formato e uma versão suportados pelo sistema.
