## O que aconteceu

O código informado é um dos doze do **catálogo legal fixo** — `AC`,
`LB_PPI`, `LB_Q`, `LB_PCD`, `LB_EP`, `LI_PPI`, `LI_Q`, `LI_PCD`, `LI_EP`,
`AC_PCD`, `AC_I` e `AC_Q` — e a criação por cadastro foi recusada.

Essa reserva precede até a checagem de unicidade de código: é propriedade do
próprio código, não do estado atual do banco. Isso importa porque o índice
de unicidade é parcial (só considera modalidades vivas) — sem esta reserva,
remover uma dessas doze liberaria o código para ser recriado por cadastro com
uma estrutura de vagas arbitrária, quando a estrutura das doze é ditada pela
norma que institui cada uma, não pelo cadastro administrativo.

## Como resolver

Não é possível criar uma modalidade com um destes doze códigos por cadastro.
Se uma dessas doze está ausente ou foi corrompida, o canal de correção é o
seed e uma migração — não a criação administrativa.
