## O que aconteceu

A etapa já recebeu decisão, de outra pessoa ou de uma requisição anterior, para ao menos uma das concessões do envio. Cada etapa recebe uma única decisão por concessão, e como a decisão é atômica nada do envio foi gravado.

## Como resolver

Recarregue a reclassificação para ver as concessões que ainda aguardam a etapa e envie a decisão só para elas.
