## O que aconteceu

O **código** do tipo de etapa excede o tamanho máximo aceito: 64 caracteres
— a contagem é feita após normalizar Unicode para a forma composta (NFC),
para que duas grafias equivalentes do mesmo texto não sejam medidas de
formas diferentes.

## Como resolver

Reduza o código para até 64 caracteres.
