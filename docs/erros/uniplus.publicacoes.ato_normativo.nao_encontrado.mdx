## O que aconteceu

O **Id** informado na consulta (`GET /atos/{id}`) não corresponde a nenhum ato
normativo registrado: o ato nunca existiu ou o Id foi digitado errado. A
resposta é 404 com o corpo de erro padrão e este código.

## Como resolver

Confira o Id informado. Para localizar o ato correto, liste os atos
(`GET /atos`) ou os atos de uma entidade
(`GET /entidades/{entidadeTipo}/{entidadeId}/atos`) e use o Id devolvido.
