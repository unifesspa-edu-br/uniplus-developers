:::warning Código ainda não emitido

Este código entra com a uniplus-api#2324, que generaliza o cadastro de motivos de
decisão por tipo. Até lá, a API não o emite.

:::

## O que aconteceu

O pedido de `PUT /api/selecao/processos-seletivos/{id}/motivos-de-decisao/{motivoId}` indicou um motivo desativado no cadastro. Motivo desativado não entra em nova escolha, mas continua valendo nos processos que já o escolheram e publicaram (UNI-REQ-0122). A recusa sai com **422**.

## Como resolver

Escolha um motivo ativo do mesmo tipo. Se o motivo desativado ainda descreve uma regra do edital, peça a quem mantém o cadastro que o reative.
