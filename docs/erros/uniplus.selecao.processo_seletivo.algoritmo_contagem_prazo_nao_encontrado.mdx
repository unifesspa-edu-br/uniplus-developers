## O que aconteceu

O pedido declarou, para o processo, uma convenção de contagem de prazo por código
e versão, mas essa combinação não é uma convenção de contagem do catálogo de regras.
Há duas causas possíveis, e a resposta não as distingue: o código com essa versão
não existe no catálogo, ou existe e é uma regra de outro tipo, que não serve para
contar prazo. A recusa sai com **422** e nada foi gravado.

## Como resolver

Consulte o catálogo de regras (`GET /api/selecao/regras-catalogo`) e escolha uma
convenção de contagem de prazo, com o código e a versão exatamente como o catálogo
os traz. Repita o pedido com esse par.

Se o catálogo não oferece a convenção desejada, não há como declará-la pelo processo:
as convenções disponíveis são as do catálogo. Enquanto nenhuma for declarada, a
publicação é recusada por
[`algoritmo_contagem_prazo_nao_declarado`](./uniplus.selecao.processo_seletivo.algoritmo_contagem_prazo_nao_declarado.mdx).
