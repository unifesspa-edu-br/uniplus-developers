Este código entra com a uniplus-api#2324, que generaliza o cadastro de motivos de
decisão por tipo. Até lá, a API não o emite.

:::

## O que aconteceu

A descrição é o texto que o candidato lê junto com a decisão. O pedido de `POST /api/selecao/admin/motivos-de-decisao` ou de `PUT /api/selecao/admin/motivos-de-decisao/{id}` veio com o campo `descricao` vazio ou só com espaços. A recusa sai com **422**, e o erro aparece no campo `descricao`.

## Como resolver

Informe a descrição, com 3 a 500 caracteres, por exemplo "Sem resultado no retorno do INEP para a edição indicada".
