## O que aconteceu

O **formato pedagógico** informado não é um dos três tokens do domínio
fechado: `PRESENCIAL`, `SEMIPRESENCIAL` ou `EAD`.

Diferente de programa de oferta, formato pedagógico tem valor padrão: se
omitido, a oferta assume `PRESENCIAL` silenciosamente. Este erro só dispara
quando um token é informado e não é um dos três válidos.

## Como resolver

Informe um dos três tokens válidos — `PRESENCIAL`, `SEMIPRESENCIAL` ou
`EAD` — ou omita o campo para aceitar o padrão `PRESENCIAL`.
