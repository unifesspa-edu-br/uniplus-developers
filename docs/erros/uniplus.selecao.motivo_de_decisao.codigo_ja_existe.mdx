:::warning Código ainda não emitido

Este código entra com a uniplus-api#2324, que generaliza o cadastro de motivos de
decisão por tipo. Até lá, a API não o emite.

:::

## O que aconteceu

O código do motivo é único **dentro do tipo** (UNI-REQ-0283). Já existe, no tipo informado em `POST /api/selecao/admin/motivos-de-decisao`, um motivo com o mesmo código, ativo ou desativado. A recusa sai com **409**.

O mesmo código em outro tipo é aceito: `DOCUMENTO_ILEGIVEL` pode existir na análise documental e na isenção da taxa.

## Como resolver

Use outro código. Se o motivo existente está desativado e descreve a mesma regra, reative-o em vez de criar outro.
