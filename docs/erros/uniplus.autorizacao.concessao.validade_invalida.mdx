## O que aconteceu

A data de fim da concessão não é posterior ao início, ou foi informada para o perfil de gestor de acessos, que não admite prazo: a concessão do gestor só termina pela revogação, que confere o mínimo de dois gestores. Os perfis de Representante do controlador e de Encarregado de dados admitem prazo, como os perfis comuns.

## Como resolver

Informe uma data de fim posterior ao início. Para o perfil de gestor de acessos, não informe data de fim.
