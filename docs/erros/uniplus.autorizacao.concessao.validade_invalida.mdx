## O que aconteceu

A data de fim da concessão não é posterior ao início, ou foi informada para perfil de gestor de acessos ou de encarregado(a) pelo tratamento de dados, que não têm concessão com prazo.

## Como resolver

Informe uma data de fim posterior ao início, ou não informe data para os perfis de governança.
