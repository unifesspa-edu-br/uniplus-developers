## O que aconteceu

Há mais de um procedimento para a mesma matéria, identificada pelo tipo de decisão e pelo alvo, quando houver. A recusa também pode ocorrer na leitura da configuração publicada.

## Como resolver

Mantenha um único procedimento para cada matéria. Se a recusa ocorrer durante a leitura de uma configuração publicada, procure o suporte do Uni+ para investigar os dados gravados.
