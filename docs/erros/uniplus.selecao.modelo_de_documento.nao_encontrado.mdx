## O que aconteceu

O identificador do modelo não corresponde a nenhum modelo de documento deste processo seletivo. A
API dá a mesma resposta para o modelo que não existe e para o modelo de outro processo: a rota de
um processo não confirma a existência de modelo alheio.

Também chega a esta resposta quem tenta confirmar um envio pendente que não foi confirmado a
tempo: o sistema remove o registro pendente depois que o prazo de envio passa, e o identificador
deixa de existir.

Na consulta do acesso, o processo é conferido antes do modelo: um processo que não existe tem
resposta própria, de processo não encontrado.

## Como resolver

Use o identificador que o início do envio devolveu para um modelo deste processo, e confira que o
processo da rota é o mesmo em que o modelo foi enviado. Se o envio ficou pendente além do prazo e
o registro foi removido, inicie um novo envio, envie o arquivo à nova URL e confirme.
