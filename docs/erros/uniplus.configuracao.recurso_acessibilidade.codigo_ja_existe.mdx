## O que aconteceu

Já existe um recurso de acessibilidade **ativo** com o código informado. O código é único entre os recursos que não foram removidos: um recurso removido libera o código.

Na atualização a conferência só roda quando o código efetivamente muda. Nada foi gravado.

## Como resolver

Use um código diferente. Se o recurso existente com esse código é o que você queria, altere-o em vez de criar outro.
