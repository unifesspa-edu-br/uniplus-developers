## O que aconteceu

O escopo informado não é aceito. Escopo de unidade exige a unidade; perfis de gestor de acessos e de encarregada de dados valem só para a instituição; os demais perfis valem só para uma unidade.

## Como resolver

Corrija o escopo do pedido: indique a unidade, ou a instituição no caso dos perfis de governança.
