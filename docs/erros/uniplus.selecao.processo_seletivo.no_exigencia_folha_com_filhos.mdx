## O que aconteceu

Um nó do envelope congelado tem `tipo: FOLHA` mas ainda assim carrega
uma lista de filhos não vazia. Roda antes de qualquer nó ser
reconstruído pelas mesmas factories da escrita — é uma checagem
estrutural rápida, feita sobre TODOS os nós de uma vez, porque
`NoExigencia.CriarFolha` nem tem um parâmetro `filhos`: se a reconstrução
tentasse prosseguir com um nó assim, ela simplesmente ignoraria os
filhos decodificados, em vez de recusar o envelope corrompido.

Na escrita normal, este cenário não existe: o handler de definição de
documentos exigidos decide entre construir uma folha ou um grupo a
partir do `tipo` do nó, e o ramo de folha nunca lê `filhos` do payload.

## Como resolver

O payload que você enviou não é a causa — é a configuração congelada
para a qual o sistema está tentando voltar que já contém a
inconsistência. Abra uma investigação em vez de tentar corrigir pelo
descarte.
