## O que aconteceu

A operação foi recusada porque o **código** do tipo de processo seletivo não
foi preenchido.

O código (ex.: `SiSU`, `PSIQ`, `PSECampo`) é a chave natural do cadastro —
único e imutável para sempre, mesmo após o tipo ser desativado: desativar
impede novos vínculos, mas não libera o código para reuso.

## Como resolver

Informe um código para o tipo de processo seletivo.
