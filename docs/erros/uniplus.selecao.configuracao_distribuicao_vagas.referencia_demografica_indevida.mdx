## O que aconteceu

Uma distribuição de vagas informou `referenciaReservaDemograficaId`, mas a
`regraDistribuicaoCodigo` não é a Lei 12.711 — é a regra institucional, onde
o quadro de vagas é inteiramente fixado pelo edital (a quantidade de cada
modalidade vem direto do payload, sem nenhum cálculo por percentual). Este
é o par simétrico de
[`referencia_demografica_obrigatoria`](./uniplus.selecao.configuracao_distribuicao_vagas.referencia_demografica_obrigatoria.mdx):
a mesma coerência, olhada do lado oposto — lá, o campo faltando quando devia
estar presente; aqui, presente quando devia faltar.

Não acumula com nenhuma outra violação — é a primeira que falhar que
interrompe a criação da configuração.

## Como resolver

Remova `referenciaReservaDemograficaId` de distribuições cuja regra não seja
a Lei 12.711, ou reveja se a regra de distribuição declarada é de fato a
pretendida para esta oferta.
