## O que aconteceu

A operação foi recusada porque a **versão do dataset** não foi preenchida ao
criar um calendário de dias úteis.

O calendário de dias úteis é reference data versionada por dataset inteiro,
não por linha: uma correção nos feriados publica um dataset novo, com a lista
completa de dias não úteis — nunca edita a lista de um dataset existente. Não
existe operação de atualização por design. A versão é o que identifica essa remessa e a distingue das anteriores: sem ela,
dois datasets do mesmo calendário ficariam indistinguíveis, e nenhum registro
que aponte para um deles diria de qual remessa de feriados se trata.

## Como resolver

Informe a versão do dataset ao criar o calendário — um rótulo que identifique
essa remessa de feriados (por exemplo, o ano ou o ciclo a que se refere).
