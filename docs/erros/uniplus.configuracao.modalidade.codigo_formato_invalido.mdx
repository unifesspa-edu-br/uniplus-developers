## O que aconteceu

Este código é compartilhado por duas causas distintas, que a entrada do
catálogo não distingue no `detail`:

- O **código da própria modalidade** não respeita o formato fechado —
  `^[A-Z0-9_]+$` (letras maiúsculas, dígitos e sublinhado, sem hífen), com no
  máximo 60 caracteres (ex.: `AC`, `LB_PPI`, `LI_Q`).
- O **código de origem** da composição `RETIRA_DE` (`composicao_origem`)
  excede 60 caracteres — este segundo caso só confere o tamanho, não o
  formato: um código de origem com caracteres fora do padrão `^[A-Z0-9_]+$`
  não é recusado aqui (a integridade referencial de que ele aponta para uma
  modalidade viva é conferida à parte, ver
  [referência inexistente ou inativa](./uniplus.configuracao.modalidade.referencia_inexistente_ou_inativa.mdx)).

## Como resolver

Se a causa é o código próprio: use apenas letras maiúsculas, dígitos e
sublinhado, com até 60 caracteres. Se a causa é o código de origem da
composição `RETIRA_DE`: reduza-o para até 60 caracteres.
