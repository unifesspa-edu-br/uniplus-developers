## O que aconteceu

O tipo de ato consultado ou referenciado não existe. Isso acontece em três
situações:

- o **Id** informado não corresponde a nenhuma versão de tipo de ato — nunca
  existiu, ou já foi removida (a remoção é sempre soft-delete);
- ao consultar a **versão vigente** de um código (`GET /tipos-ato/{codigo}/vigente`),
  o código não existe;
- ao consultar a versão vigente, o código existe, mas **nenhuma versão dele
  vale na data pedida** — a data cai fora de toda janela de vigência (o fim da
  janela é exclusivo) ou só existe versão futura. A consulta pergunta "qual
  versão deste tipo vale na data?", e a resposta para "nenhuma" é uma só, a
  mesma do código inexistente. Para ver as versões futuras, liste os tipos de
  ato com `vigentes=false` (`GET /tipos-ato`) ou informe `data` na consulta da
  versão vigente.

Esta causa aparece ao **consultar** um tipo de ato por Id ou por código
vigente, e ao **atualizar** ou **remover** por Id.

## Como resolver

Confira o Id ou o código informado e, na consulta da versão vigente, a data.
Se o tipo de ato existia antes, é possível que
tenha sido removido — remoção nunca é bloqueada por atos publicados sob
ele, porque o ato copia os atributos do tipo por valor no instante da
publicação, e continua legível mesmo depois. Liste os tipos de ato
vigentes para localizar o Id correto.
