## O que aconteceu

O **Id** informado não corresponde a nenhuma versão de tipo de ato
existente — nunca existiu, ou já foi removida (a remoção é sempre
soft-delete).

Esta causa aparece apenas ao **atualizar** ou **remover** um tipo de ato
por Id. A leitura (`GET`, por Id ou pela lista) usa o mecanismo padrão de
404 do protocolo HTTP quando o recurso não existe, sem o campo `code` — a
resposta ainda é 404, mas sem corpo `ProblemDetails` associado a esta
entrada do catálogo.

## Como resolver

Confira o Id informado. Se o tipo de ato existia antes, é possível que
tenha sido removido — remoção nunca é bloqueada por atos publicados sob
ele, porque o ato copia os atributos do tipo por valor no instante da
publicação, e continua legível mesmo depois. Liste os tipos de ato
vigentes para localizar o Id correto.
