## O que aconteceu

Uma das distribuições de vagas do payload informou `voBase` menor ou igual a
zero. `VO_base` (vaga-oferta original) é o número de vagas da oferta de
curso antes de qualquer cálculo de distribuição — o insumo do qual toda a
distribuição por modalidade parte (art. 10, II); um valor zero ou negativo
não tem interpretação válida como ponto de partida.

Esta checagem acumula com
[`pr_fora_do_limite`](./uniplus.selecao.configuracao_distribuicao_vagas.pr_fora_do_limite.mdx)
e
[`modalidades_vazias`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidades_vazias.mdx)
— as três únicas checagens que não dependem de nenhuma resolução contra
cadastro ou catálogo vivo já resolvida (oferta de curso e modalidades, em
Configuração; regra de distribuição, no `rol_de_regras` do próprio módulo
Seleção). Elas rodam numa primeira passada, sobre **todas** as distribuições
do payload, antes de qualquer uma dessas consultas: um payload com duas
distribuições, uma com `voBase` inválido e outra com `pr` fora da faixa,
devolve as duas violações juntas no array `errors[]` do corpo de erro, cada
item com seu `field` (`distribuicaoVagas[<índice>].voBase`, por exemplo).

Esta checagem **não** acumula com
[`modalidade_duplicada`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidade_duplicada.mdx)
— essa outra só é avaliada depois que a passada de forma vem inteiramente
limpa para todas as distribuições, então as duas nunca aparecem juntas na
mesma resposta.

Este código também aparece no **descarte de retificação**: reconstruir o
grafo a partir do envelope congelado recomputa cada
`ConfiguracaoDistribuicaoVagas` a partir dos mesmos insumos (`voBase`, `pr`,
regras, modalidades) — a mesma checagem do domínio roda de novo, e um
`voBase` inválido no envelope congelado sai daí com este código, sem
acumular com outra violação (a reconstrução para na primeira distribuição
com problema).

## Como resolver

Informe um `voBase` positivo para cada distribuição de vagas do payload. Se
a resposta trouxer mais de uma violação no array `errors[]`, corrija todas
antes de reenviar.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
