## O que aconteceu

A confirmação do envio foi pedida para um modelo que não está pendente: ele já foi confirmado,
inclusive por outra confirmação feita ao mesmo tempo. O modelo confirmado é imutável, e um novo
envio cria outro modelo, sem sobrescrever o anterior.

Esta é a última conferência da confirmação: ela vem depois de o servidor encontrar o modelo, ler o
arquivo no armazenamento e validar tamanho e conteúdo. Por isso, repetir a confirmação de um
modelo já confirmado pode responder antes com alguma das outras causas, como
[`objeto_nao_encontrado`](./uniplus.selecao.modelo_de_documento.objeto_nao_encontrado.mdx), se o
arquivo já não estiver no armazenamento.

## Como resolver

Não repita a confirmação. Se a confirmação anterior respondeu com sucesso, o modelo já está
confirmado e pode ser citado pelas exigências do processo. Para usar outro arquivo, inicie um novo
envio.
