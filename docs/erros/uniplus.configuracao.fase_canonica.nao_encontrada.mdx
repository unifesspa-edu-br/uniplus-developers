## O que aconteceu

O identificador informado não corresponde a nenhuma fase canônica existente
— ou porque nunca existiu, ou porque já foi removida (soft delete).

A remoção de uma fase canônica nunca é bloqueada — o único consumo é por
snapshot-copy desacoplado no módulo Seleção (ADR-0061), sem chave
estrangeira intra-banco apontando para esta entidade.

## Como resolver

Confira o identificador da fase. Se ela foi removida, cadastre uma nova ou
use outra já existente.
