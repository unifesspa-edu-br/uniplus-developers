## O que aconteceu

Uma regra de derivação não booleana não informa um código em `contribui`. Na definição das regras padrão, a ausência de `contribui` identifica uma regra booleana; na avaliação de formulário, a natureza booleana é declarada separadamente.

## Como resolver

Para uma regra não booleana, informe em `contribui` o código de valor do fato. Para uma regra booleana, use a forma própria da operação.
