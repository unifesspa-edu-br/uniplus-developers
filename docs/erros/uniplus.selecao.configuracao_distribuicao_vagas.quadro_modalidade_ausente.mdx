## O que aconteceu

> **Atenção ao título.** O título fixo desta entrada ("...não tem quantidade
> fixada pelo edital") descreve só um dos dois cenários abaixo. No cenário
> do ramo federal, o problema não é falta de quantidade — leia os dois
> antes de agir pela primeira leitura do título.

Este código dispara em duas situações distintas, ambas sobre a mesma
fronteira entre o que é calculado e o que é declarado:

- **Ramo institucional.** Numa distribuição de vagas com
  `regraDistribuicaoCodigo` institucional (não Lei 12.711), uma das
  modalidades selecionadas não tem quantidade fixada em `quadro`. No ramo
  institucional não há cálculo — o quadro é inteiramente declarado pelo
  edital, então toda modalidade selecionada precisa ter sua quantidade
  explícita; não há valor padrão nem fórmula que preencha a lacuna.
- **Ramo federal, modalidade com código fora do vocabulário legal.** Numa
  distribuição pela Lei 12.711, uma modalidade selecionada tem composição
  `DENTRO_DO_VR` ou `RESIDUAL_DO_VO` (as composições que a fórmula do art.
  10 calcula), mas o código dela não é um dos 9 códigos federais fixos (as
  8 sub-reservas mais `AC` — ver
  [`modalidades_federais_incompletas`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidades_federais_incompletas.mdx)).
  O cadastro de modalidades de Configuração não impede essa combinação —
  nada impede cadastrar, por exemplo, uma modalidade de código próprio com
  composição `DENTRO_DO_VR` —, mas a fórmula legal só calcula quantidade
  para os 9 códigos que ela conhece; uma modalidade calculada com outro
  código nunca aparece no quadro que a fórmula produz.

Nos dois casos, `emitido_em` é o mesmo, mas a remediação é diferente — leia
com atenção qual dos dois cenários corresponde ao seu caso antes de agir.
Não acumula com nenhuma outra violação — é a primeira modalidade com o
problema, na ordem em que foram selecionadas, que interrompe a criação da
configuração.

Este código também aparece no **descarte de retificação**: reconstruir o
grafo a partir do envelope congelado recomputa a `ConfiguracaoDistribuicaoVagas`
inteira a partir dos mesmos insumos — não apenas essa checagem, o cálculo
inteiro roda de novo. Como os insumos são bit-a-bit os mesmos que
produziram o resultado originalmente congelado, o recálculo chega ao mesmo
resultado; esta causa só reaparece no descarte sob envelope corrompido, ou
se a lógica de cálculo mudou de versão entre o congelamento e o momento do
descarte.

## Como resolver

**Se a distribuição é institucional:** informe a quantidade de vagas
(`quantidadeDeclarada`, via o bloco `quadro` do payload) para toda
modalidade selecionada.

**Se a distribuição é pela Lei 12.711:** o problema não é falta de
quantidade no payload — informar uma produziria
[`quantidade_calculada_nao_informavel`](./uniplus.selecao.configuracao_distribuicao_vagas.quantidade_calculada_nao_informavel.mdx),
não este código. A modalidade ofensora nunca é uma das 9 federais mal
codificada — a checagem de
[`modalidades_federais_incompletas`](./uniplus.selecao.configuracao_distribuicao_vagas.modalidades_federais_incompletas.mdx)
já garante que as 9 estão presentes com seus códigos corretos antes de
chegar aqui; é sempre uma modalidade **extra**, selecionada além delas.
Remova essa modalidade da seleção da oferta, ou corrija sua composição no
cadastro de Configuração para `RETIRA_DE`/`SUPLEMENTAR_AO_TOTAL` (que
exigem quantidade declarada, não calculada) se ela deveria mesmo compor
esta oferta federal — no ramo federal, `RETIRA_DE` só é aceita com origem
`AC` (ver
[`retirada_federal_deve_ser_de_ampla_concorrencia`](./uniplus.selecao.configuracao_distribuicao_vagas.retirada_federal_deve_ser_de_ampla_concorrencia.mdx)).
O código da modalidade, em si, não pode ser alterado — é imutável no
cadastro.

Se o erro apareceu ao descartar uma retificação, o problema não está no
payload enviado agora — está na configuração congelada para a qual o
descarte está tentando voltar. Isso indica uma inconsistência na versão
publicada anterior; abra uma investigação em vez de tentar corrigir pelo
descarte.
