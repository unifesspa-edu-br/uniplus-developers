## O que aconteceu

O dataset trouxe duas entradas com a **mesma data, abrangência, município e
UF** — uma repetição do mesmo dia não útil dentro do próprio envio.

A checagem de duplicidade é sobre a combinação dos quatro campos, não só a
data isolada: a mesma data pode aparecer mais de uma vez no dataset desde que
represente abrangências diferentes (por exemplo, um feriado nacional e, na
mesma data, um recesso institucional local) — o que não pode é repetir a
exata mesma combinação duas vezes.

## Como resolver

Revise a lista de dias não úteis e remova a entrada duplicada, mantendo
apenas uma ocorrência de cada combinação de data, abrangência, município e
UF.
