## O que aconteceu

A estrutura do arquivo não corresponde ao leiaute escolhido: número de campos diferente, CPF, número de inscrição ou nota fora do formato, codificação que não é UTF-8, linha em branco no meio do arquivo, arquivo sem linhas, ou prova marcada como ausente com nota diferente de zero numa área. O arquivo é recusado inteiro, sem gravar nenhuma nota, para que a nota de uma área nunca seja gravada como se fosse de outra (UNI-REQ-0174). A mensagem de detalhe aponta a linha e a coluna, nunca o conteúdo, porque o arquivo traz dados pessoais.

## Como resolver

Confira se o leiaute escolhido é o do arquivo: o retorno de 20 campos vale para as edições a partir de 2024. Não edite o arquivo para fazê-lo passar. Se o INEP mudou o formato e o leiaute certo não está no catálogo, acione a equipe técnica. Quando a recusa é de prova ausente com nota, o arquivo está incoerente: peça ao CEPS o arquivo corrigido junto ao INEP e importe-o.
