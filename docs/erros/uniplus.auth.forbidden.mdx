## O que aconteceu

O token enviado é válido e a requisição está autenticada, mas o endpoint
exige uma role ou claim que este token não carrega. É diferente de
[`uniplus.auth.unauthorized`](/erros/uniplus.auth.unauthorized): ali não
havia identidade reconhecível; aqui a identidade é reconhecida, e mesmo
assim não tem a permissão exigida para este recurso específico.

## Como resolver

Se você acredita que deveria ter acesso a este recurso, o problema não está
na requisição — é a role ou o vínculo institucional da sua conta que precisa
ser ajustado. Procure quem administra permissões no seu órgão/setor para
verificar seu perfil de acesso. Repetir a requisição com o mesmo token não
muda o resultado.
