## O que aconteceu

A unidade que se tentou remover é a **unidade raiz** (o vínculo com a
reitoria) de uma instituição viva.

A instituição — o registro singleton que descreve a própria IES —
referencia sua unidade raiz por Id. Remover essa unidade deixaria a
instituição apontando para um registro inexistente, quebrando o vínculo
que a identifica como reitoria.

Esta é uma checagem *check-then-act*: sob concorrência entre a remoção
desta unidade e o cadastro simultâneo de uma instituição que a escolhe
como raiz, a janela entre a checagem e a gravação não é fechada por uma
restrição de banco — é controle de concorrência ainda em aberto, tratado
como cross-cutting comum a todos os cadastros, não específico desta
operação.

## Como resolver

Antes de remover a unidade, atualize a instituição para apontar para
outra unidade do tipo reitoria como raiz, ou remova a instituição
primeiro, se for o caso.
