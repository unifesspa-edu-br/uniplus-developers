# Portal de desenvolvedores do Uni+

Bem-vindo à documentação do **Uni+** (Sistema Unificado Unifesspa — S2U), a
plataforma unificada de processos institucionais da Universidade Federal do Sul
e Sudeste do Pará.

Este portal consolida, em um só lugar acessível ao time de desenvolvimento, ao
P.O. e demais interessados:

## Trilha de Produto e Domínio

Para entender **o que** o sistema faz e **por quê**:

- **Requisitos** funcionais e não funcionais
- **Regras de negócio** (cotas, bônus regional, concorrência dupla, congelamento de parâmetros)
- **Casos de uso** por etapa do ciclo de vida do edital
- **Glossário** do domínio

## Trilha de Referência de API

Para integrar com a plataforma:

- **Especificações OpenAPI** renderizadas por módulo
- **Catálogo de erros** (resolução dos `type` URIs de `ProblemDetails`)
- **Catálogo de media types** versionados
- **Changelog** de versões

## Dados de exemplo

Todos os exemplos deste portal — payloads, prints, tabelas — usam exclusivamente
a lista canônica de [**personas fictícias**](personas/cadastros.mdx).
Nenhum dado de pessoa real aparece na documentação.

:::note[Domínios]
Este conteúdo é servido no domínio de trabalho `developers.portaluni.com.br`.
O domínio institucional `developers.uniplus.unifesspa.edu.br` é reservado para
produção.
:::
